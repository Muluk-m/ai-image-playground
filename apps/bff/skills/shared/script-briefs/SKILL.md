# 剧本设定

热门设定由画布上的剧本设定器写入文本节点。正文已经包含大纲、人物表和第 1 集。不要另写一套去覆盖用户确认过的正文。

用户要求拆剧本时：

1. 先用 `readCanvas` 读取文本节点原文。
2. 调用 `applyScriptPlan`。人物、地点、道具建成没有图片的素材节点，分镜写入分镜表，并按引用连线。
3. `lookIds` 只填本轮人物素材 id，`locationId` 只填地点素材 id。道具可以建节点，不要把它当成人物或地点。
4. 不提交生图或生视频，也不调用运行节点。这个工具不生成媒体，也不计费。

拆完之后用户要出图时，顺序是先素材、后首帧：先用 `runNodes`（stage 写「素材」）给素材节点出图，素材都有图之后再用 `runStoryboardFrames` 出首帧。首帧节点由它自己铺，不要手工建。

用户要求续写第 N 集时，在同一次 `applyScriptPlan` 里用 `episode` 追加。N 从 2 开始。该集标题已经在剧本里时不要覆盖，先告诉用户。

不确定的画面不要说成已经生成的图片。
