# 海报与营销物料

> 示例级内容，尚未经过真实投放数据验证。

海报和主图是两件事：主图要「一眼认出是什么」，海报要「一眼被吸引住」。
海报允许留白、允许氛围、允许大标题，但**文字是它最容易翻车的地方**，整条流程都得围着这一点转。

## 先把这四件定下来

1. **主体** —— 有商品实拍图 / logo / 人物图就 `editImage`，`imageIds` 第一项是要放进海报的那张；
   纯氛围海报没有素材时才 `generateImage`。用户提到某个素材却没引用，先 `readLibrary` 查一下。
2. **画幅** —— 用户没说就按用途推：朋友圈与小红书竖版、公众号头图与网页 banner 横版、
   商品位方图。在回复里说一句你按哪个定的。
3. **文案** —— 主标题、副标题、行动号召各一句。**用户没给文案就替他写，别问**；
   写完把原文列在回复里让他核对。
4. **语言** —— 跟着投放渠道走：淘宝 / 京东 / 拼多多 / 1688 / 小红书 / 抖音 → 中文简体；
   Amazon / Temu / Shopee / TikTok Shop / AliExpress 等跨境 → 英文。
   他没说渠道就按中文简体做并说明。

方向本身有两种以上差很远的走法时（例如「618 海报」可以是价格轰炸也可以是质感种草），
才调澄清工具给 2-4 个具体方向让他单选，每个方向一句话写清会产出什么。

## prompt 怎么写

一条 `prompt` 里按这四段写，每段一句：

1. **主题**：这张海报在讲什么事（新品上市 / 限时折扣 / 品牌周年）
2. **主视觉**：画面中心是什么、占多大、放在哪
3. **风格氛围**：色调、光线、质感、情绪（「暖色调、柔光、克制的高级感」）
4. **版式**：标题放哪、副标题放哪、留白留在哪、行动号召放哪

再加一句约束：不要生成除指定文案外的任何文字、水印、logo。

## 文字：两条路，选一条并告诉用户

模型写出来的中文字经常糊、错字、缺笔画。所以：

1. **推荐**：**海报里只放一句短标题**（不超过 8 个字），其余文案排在画面外由用户自己叠。
   出图时在 prompt 里把这句话的原文写死，并要求「除此之外不出现任何文字」。
2. 用户坚持要整版文案排进去：照做，但生成后**逐字列出你要求生成的文案**，
   让他对着图核对，并说明「模型写的字可能不准确，投放前请人工确认」。

**永远不要在海报里生成价格、日期、参数、法律声明这类硬信息**——错一个数字就是投放事故。
用户要这些，就把位置留白，让他自己叠字。

## 出几版

- 用户没说就出一版。
- 「多几个版本挑」→ 用 `generateImage` / `editImage` 的 `n` 出同一方案的多版。
- **不同方向（不同配色、不同版式）要分别调用**，别指望 `n` 撞出两个方向。

## 改稿

海报通常是改出来的，不是一次出来的：

- 版式不对、颜色不对、某个元素多余 → `editImage`，`imageIds` 第一项填要改的那一版，
  `prompt` 只说改哪一处，其余一切保持不变。
- 文字写错了 → 同样 `editImage`，把正确的原文写死，并要求版式与配色不动。
- 方向整个不对 → 回到上一步重开一个方向，不要在错的那版上反复叠加。

## 用户明说的约束不许静默丢掉

画幅、必须出现的元素、必须避开的颜色、品牌规范——他说了就照做。
**做不到的先说再动手**，不要生成完了才补一句「顺便告诉你没满足」。

## 交付

一句话说清：你替他定了什么（画幅、语言、方向）、这一批是几次生图、
图里有哪些文字需要他逐字核对。再给 1-2 个具体的下一步（换个配色出一版 / 按这版补一张横版）。
