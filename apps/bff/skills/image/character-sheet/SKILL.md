# 三视图设定图

> 示例级内容，尚未经过真实产出验证。

设定图的价值全在**一致性**：以后每一张图都拿它当参考，人物才不会一张一个样。所以这份图本身要尽量「中性」——正光、无戏剧性构图、无强风格滤镜。

## 交付方式：默认直接出完整三视图

**默认不问，直接按分支一交付完整三视图**，并在回复里带一句「想先看正面定妆图确认造型再出三视图也行，说一声我重来」——用户随时可以改，不必先拿一次提问换。

用户已经明说「直接出完整三视图」或「先看正面」时，照他说的那一种走。
只有他自己表达了犹豫（「先看看效果」「不确定造型对不对」「先出一张试试」）才用 `askClarification` 问一次：

- `question`：「你想直接生成完整三视图，还是先出一张正面图看看效果？」
- `options`：[「直接生成完整三视图（正面、侧面、背面）」、「先出正面图，确认造型后再生成三视图」]

问了就结束这一轮等他选，**不要同时调用生图工具**；他的选项回复就是下一轮的执行指令，不要重复询问。
明确只要表情集或某些其他角度时，按实际要求执行，不套用三视图的二选一。

已有多张照片逐张调整机位、主体朝向或背景，不属于本技能的设定板流程：每张照片应作为独立目标分别调用 `editImage`，不要把它们合成一张三视图，也不要把其它待处理照片当作参考图。只有用户要一张图内的正面 / 侧面 / 背面等多个视角，或明确要可复用的角色 / 物品设定图时，才走本技能。

## 分支一：直接生成完整三视图

默认交付**一张同时包含正面、90° 侧面、180° 背面的完整设定图**，不是只有正面的单张图，也不是三张随机变体。

- 没有参考图：用 `generateImage`，`n` 为 1，根据用户描述完成角色设计并直接生成完整三视图。
- 有参考图：用 `editImage`，`n` 为 1，`imageIds` 第一项填用户指定的角色基准图，沿用外观生成完整三视图。
- 提示词明确写出三个视角、从左到右排列、相同全身比例与高度、同一角色的外观与服装一致，纯色背景、均匀布光，三个视角互不遮挡且不裁切。
- **不要先单独生成正面图再等确认**，这是默认交付。用户明确要求分开三张时才分别生成各视角，固定同一基准图，不用 `n` 为 3 代替三个角度的明确指令。

## 分支二：先看正面效果（用户自己要的时候才走）

仅生成一张正面定妆图。无参考图时用 `generateImage`；有参考图时用 `editImage` 保留其外观，`imageIds` 第一项填基准图。`n` 为 1，提示词写清：

- 主体类别与身份，遵循用户描述
- 外观：发型发色、脸型、瞳色、服装、配饰、体型；有参考图时以参考图为准
- 光线：正面均匀布光，无强阴影
- 背景：纯色（浅灰或白），无场景、无道具
- 构图：全身、正面、居中、站姿自然

回复明确说明「这是正面预览，三视图尚未生成」，等待用户确认造型。用户要求修改时先改正面；**未确认前不继续生成其他视角**。
用户确认后，把确认过的正面图作为唯一基准，用 `editImage` 按分支一生成完整三视图，不再重复问交付方式，也不只补一张侧面就停下来。

外观细节遵循用户已有描述，合理补充的部分简短说明，不为了凑齐设定连环追问。用户中途喊停就停。

## 表情集 / 物品多角度

同样的做法：基准图不变，每次 `editImage` 只改一件事（换表情、换一个角度、换一种材质），其余全部要求保持。

## 一致性守则

- **基准图保持固定。** 有用户指定或确认的角色图时，后续每一次 `editImage` 的 `imageIds` 第一项都填它；直接生成完整三视图且没有先前参考图时，以这张设定图为后续基准，不随意换成中间变体。
- 某个角度出来不对，**回到基准图重出那个角度**，不要在错的那张上接着改。
- 不要在设定图里加场景、道具、特效光。那些留给用图的时候再加。

## 这组图不是视频首帧

设定图是**参考**，不是画面：三视图拼在一张图里，正面侧面背面同时出现。
把它当成视频的起始画面，出来的片子就是一张三视图在动——这是一个真实发生过的翻车。
要让这个角色出现在视频里，先用它当参考 `editImage` 画出一张**单一视角的完整画面**，
拿那张去做首帧。

## 交付

按所选分支说明实际完成的内容，正面预览不能称为完整三视图。完整交付后告诉用户：

1. 这一批是几次生图，哪一张是基准图
2. 这组图以后可以直接在输入框里引用，或者存进素材库，之后要画这个角色时用 `editImage` 带上它当参考
3. 1-2 个具体的下一步：补一组表情 / 让这个角色进某个场景 / 按它出一张海报
