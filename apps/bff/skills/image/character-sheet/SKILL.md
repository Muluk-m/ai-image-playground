# 三视图设定图

> 示例级内容，尚未经过真实产出验证。

设定图的价值全在**一致性**：以后每一张图都拿它当参考，人物才不会一张一个样。所以这份图本身要尽量「中性」——正光、无戏剧性构图、无强风格滤镜。

## 先定外观，再出三视图

一上来不要直接出三视图。**先出一张正面定妆图**，让用户确认外观：

`generateImage`，`n` 为 1，`prompt` 里逐项写死：

- 主体类别与身份（「25 岁东亚女性，插画师」／「一只陶瓷保温杯」）
- 外观逐项：发型发色、脸型、瞳色、服装（上衣 / 下装 / 鞋 / 配饰各写一句）、体型
- 光线：正面均匀布光，无强阴影
- 背景：纯色（浅灰或白），无场景、无道具
- 构图：全身、正面、居中、站姿自然

用户已经有人物图时**跳过这一步**，直接把那张图当基准。

意图清楚就直接做，把你替他定的外观细节在回复里说一句，别为了凑齐设定连环追问。
只有「这个角色该长什么样」本身有两种以上差很远的走法时，才调澄清工具给 2-4 个具体方向让他单选。

## 再出其余视角

用户确认正面图后，用 `editImage` 逐个角度出，`imageIds` 第一项固定填那张确认过的正面图：

- 侧面（90°）
- 背面（180°）
- 需要时再加 3/4 侧（45°）

每次 `prompt` 只说两件事：**换成哪个角度**，以及**其余一切保持与参考图完全一致**（同一个人、同样的发型服装配饰、同样的光线、同样的背景、同样的画风与线条粗细）。
一个角度一次调用，`n` 为 1。**不要用 `n` 一次出多张指望里面有一张对**——不同的角度是不同的方案。

**该出的角度一次出完**，不要出了正面和侧面就停下来等用户说「继续」。
用户中途喊停就停，剩下的不要自作主张跑完。

## 表情集 / 物品多角度

同样的做法：基准图不变，每次 `editImage` 只改一件事（换表情、换一个角度、换一种材质），其余全部要求保持。

## 一致性守则

- **基准图只有一张。** 拿第二张图当基准就会开始漂。后续每一次 `editImage` 的 `imageIds` 第一项都填最初那张确认过的图。
- 某个角度出来不对，**回到基准图重出那个角度**，不要在错的那张上接着改。
- 不要在设定图里加场景、道具、特效光。那些留给用图的时候再加。

## 这组图不是视频首帧

设定图是**参考**，不是画面：三视图拼在一张图里，正面侧面背面同时出现。
把它当成视频的起始画面，出来的片子就是一张三视图在动——这是一个真实发生过的翻车。
要让这个角色出现在视频里，先用它当参考 `editImage` 画出一张**单一视角的完整画面**，
拿那张去做首帧。

## 交付

出完之后告诉用户：

1. 这一批是几次生图，哪一张是基准图
2. 这组图以后可以直接在输入框里引用，或者存进素材库，之后要画这个角色时用 `editImage` 带上它当参考
3. 1-2 个具体的下一步：补一组表情 / 让这个角色进某个场景 / 按它出一张海报
