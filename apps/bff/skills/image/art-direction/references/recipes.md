# 按类别的完整示例

> 改编自 OpenAI Codex 内置 imagegen 技能的 sample prompts（Apache-2.0）。

这些是**写满的配方**，用来校准每一类该写到多细，不是每次都要补这么多。用户已经给了的取舍一律照他的来；
只从这里借结构与用词，不借示例里的具体主体、品牌或文案。

## 生成

### 写实摄影

```text
用途：写实摄影 · 纪实人像
主体：一位年迈的渔夫在小渔船上整理渔网，脸上有日晒皱纹
场景：近海水面，薄雾
画风：写实抓拍照片，不摆拍
构图：中近景，平视
光线与氛围：海边柔和日光，浅景深，轻微胶片颗粒
材质：真实皮肤纹理、磨旧的衣物、被海盐侵蚀的木头
约束：自然色彩，不重度修图，不美化；无水印
避免：影棚打光感、摆拍感
```

### Logo 品牌

```text
用途：Logo 品牌 · 社区面包店标志
主体：面包店「麦田与面粉」的原创标志
画风：矢量标志，扁平色，极简
构图：单个标志居中，纯色背景，四周留足边距
配色：1-2 色，高对比
约束：轮廓强、负空间平衡；原创；无渐变、无样机、无 3D；无水印
```

变体写法：抽象图形标（「几何叶形符号，暗示可持续与生长」）、字母组合（「AV 两个字母交织」）、
纯字标（「Studio North，字距均匀」）——都保持扁平、无渐变、无样机。

## 按用途的模板

```text
用途：<写实摄影 | 风格概念 | 商品图 | 信息图> · <落地页头图 / 分区插图 / 博客题图>
主体：<画面主角>
场景：<环境或抽象背景>
画风：<摄影 / 插画 / 3D>
构图：<宽幅或居中；需要时写明给文案留出的空白>
光线与氛围：<柔和 / 明亮 / 中性>
配色：<品牌色或中性色>
约束：无文字；无 logo；无水印；需要时给界面留位
```

### 游戏素材（场景 / 角色 / 图标 / 贴图）

```text
用途：风格概念 · <场景概念 / 角色设定 / 游戏 UI 图标 / 可平铺贴图>
主体：<地貌 / 场景 / 角色 / 图标 / 材质>
画风：<写实或风格化>；<概念艺术 / 角色渲染 / UI 图标 / 贴图>
构图：<远景 / 俯视>；<机位>；<视觉焦点>
光线与氛围：<时段>；<情绪>；<体积光 / 雾气>
约束：无 logo 与商标；无水印
```

贴图额外要求：无缝平铺、没有明显焦点、无文字。图标额外要求：居中、四周留边、轮廓清楚、无背景场景。

### 线框图

```text
用途：界面设计 · <网页 / 移动端> 线框图
主体：<按顺序列出各区块；栅格与列数；关键标签>
画风：低保真灰度线框
构图：<横版桌面 / 竖版手机>
约束：标出主要区块；无颜色；无 logo；无真实照片；无水印
```

## 改图

每条都先写「只改什么」，再写「保留什么」，迭代时每次重复保留项。

- **换文字语种**：图 1 是原图；把「A」「B」逐项换成「甲」「乙」；只改文字，版式、字体、间距、层级不变，不增词。
- **保人物身份**：图 1 是人物照，图 2 起是服装参考；只换服装；脸、体型、姿态、发型、表情不变，光影匹配，背景不变。
- **精确替换物体**：图 1 是房间照；只把白色椅子换成木椅；机位、室内光、地面阴影和其余物体不变。
- **只改光线天气**：图 1 是原图；改成下着小雪的冬日傍晚；主体、几何、机位、构图不变，只改光线、氛围与天气。
- **风格迁移**：图 1 是风格参考；把它的配色、纹理、笔触用到新主体上；不加额外元素。
- **多图合成**：图 1 是底图，图 2 是要放进去的主体；把图 2 的主体放到图 1 人物旁；光线、透视、比例匹配，底图构图不变。
- **角色一致性**：图 1 是角色定稿；同一角色进入新场景做新动作；不重新设计角色，五官、比例、服装、配色、性格不变。
- **草图转渲染**：图 1 是手绘；转成写实图；布局、比例、透视不变，材质与光线为草图服务，不加新元素和文字。
