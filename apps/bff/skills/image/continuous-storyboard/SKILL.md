# 连续分镜图

把用户的故事画成一张按阅读顺序推进的分镜图。它交付图片，不启动视频生产流程。

## 整理输入

有剧情就按剧情做，不为补表单连环提问。只有参考图、没有任何情节时，一次问清要发生什么。
用户已明确格数或布局时按其要求；否则默认六格，2行3列。
人物参考图只用于保持身份；场景参考只用于保持空间。多张图分别是什么用途要写清，不能把三视图本身当成第一格画面。

## 先把每格的具体事件写进出图提示词

每格写一个可以看见的动作，包含人物、景别、位置、道具状态和下一格如何衔接。
例如「看见桌上的信封 → 伸手拿起 → 拆开 → 阅读 → 抬头 → 走向门口」，不是「交代 / 发展 / 高潮」六个空泛标签。
剧情有明确顺序时不得打乱。动作跨格连续，人物的运动方向、视线和持有的道具随事件变化；换机位服务叙事，不能用同一动作的六个角度代替六个事件。

默认出图约束以末尾的「默认出图约束」为准。有参考图调用 `editImage`，imageIds 第一项是主基准；无参考图调用 `generateImage`。n 为 1，只生成一张分镜拼图。
按当前工具提供的拟稿与确认流程提交；不先逐格生成，也不把 n 设置为格数。

## 交付前检查

核对格数、阅读顺序、人物外观、服装、道具状态、动作衔接和场景空间关系。
拼图是分镜参考，不能直接当作视频首帧；拍某一镜时先用宫格切分取得单格，再按实际需求生成完整首帧。
交付时说清是一张几格拼图，指出尚存的一致性问题。用户要拆图或生成视频时再处理，不自动追加这些任务。
