# 图片本地化

> 示例级内容，尚未经过真实投放数据验证。

做一件事：**图上的字换个语种，别的一概不动**。
一张已经做好的中文详情图要投 Amazon，用户要的是同一张图的英文版，不是另一张图。

**这条路最大的风险是模型写不准字。** 整条流程都得围着这一点转：先承认它，再把损害控住。

## 直接干活

用户指着一张图说「翻成英文」「做个西语版」，意图只有一种解读，**不要先问一轮**。

`editImage`：

- `imageIds` 只填要翻译的那一张。产出落在它旁边，源图不动。
- `n` 保持 1。一张图一次调用；**多张图要逐张分别调用**，不要指望一次全翻完。
- 用户提到某张素材却没引用，先 `readLibrary` 按名字查图片 id。

## 目标语言：能从平台推出来就不要问

用户说了要投哪个平台，语言就跟着平台走：

- 淘宝 / 天猫 / 京东 / 拼多多 / 1688 / 小红书 / 抖音 → 中文简体
- Amazon / Temu / Shopee / TikTok Shop / AliExpress / eBay / Lazada → 英文
- 用户直接点名语种（日语、韩语、德语、西班牙语、俄语、法语、葡萄牙语、繁体中文…）就照他说的

**既没说平台也没说语种**才需要问，而且问法是调澄清工具给 2-4 个**具体语种**让他单选
（按他的商品与常见投放地排序），不要问「你想翻成什么语言」。

## prompt 怎么写

三句，一句一件事：

1. **翻什么**：把图中所有文字翻译成某某语言。
2. **怎么排**：字号、字重、颜色、对齐方式、每一块文字在画面里的位置与占位大小保持不变；
   目标语言更长时在原文字块内缩小字号或换行，**不许挤占画面、不许挪动其他元素**。
3. **不动什么**：商品、背景、配色、构图、光影、图标一概不变；
   logo 与品牌名、型号、规格代号**保持原文不翻译**。

第 3 句里的「logo 与品牌名不翻译」必须写。省掉它，品牌名会被译成一个不存在的词。

## 哪些字不该翻

- 品牌名、商标、店铺名 —— 原样保留
- 型号、SKU、规格代号 —— 原样保留
- 价格、日期、认证编号、法律声明 —— **一律不要让模型重画**。用户要改这些，让他自己叠字；
  错一个数字就是投放事故。

用户圈了选区只翻某一块时，带上 `selectionBindings`，逐项抄图片 id 与选区 id。
选区是编辑边界，圈外的字不要动。

## 交付时必须做的一件事

**把你要求生成的译文逐条列在回复里**，让用户对着图核对。格式就是「原文 → 译文」一行一条。

然后说一句：模型是把字重画上去的，**可能出现错字、缺笔画、字距异常，投放前必须人工逐字确认**；
需要绝对准确的版本，建议把原图的可编辑源文件拿去改。

这句提醒不是客套，是这条技能的验收条件。不说它就等于把一张可能有错字的图交出去当成品。

## 出来不对怎么办

- **字糊了 / 有错字**：`imageIds` 仍从**原图**出发重出，把那一句译文原文写死在 prompt 里。
  不要在有错字的产出上接着改，错误会叠加。
- **版式被改了**：第 2 句写得更死，逐项点名（字号、位置、对齐、行数），重出。
- **画面跟着变了**：第 3 句逐项点名商品、背景、配色、光影，重出。
- **译文太长排不下**：先把译文改短（这是文案问题，不是生图问题），再重出。

## 交付

说清四件事：翻成了什么语言、这一批是几次生图（几张图就是几次）、
译文逐条列出、以及那句人工核对的提醒。
再给 1-2 个具体的下一步：把同一套里的其余几张也翻掉 / 再出一个语种。
