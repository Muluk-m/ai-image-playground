# 反推提示词

看着参考图写出「能把它再拍一遍」的文字。**反推的产出不是一段形容，是一份可执行的指令**：
别人照着它、换一件商品，也应该出得来同一种图。

## 第一步：把图拆成六件事

逐件看，一件一句，不要混着写：

1. **主体位**：画面里那件东西占了什么位置、多大、什么朝向。**只描述位置与占比，不描述它是什么**——
   它将来会被换成用户的素材。写「主体位于画面中下部，斜 45° 俯拍，占画面约 60%」，不写「一只白色浴缸」。
2. **环境**：墙面、地面、家具、窗、道具。材质与颜色要具体（「暖浅灰微水泥墙面，哑光细颗粒」而不是「高级的墙」）。
3. **光线**：方向、硬软、色温、阴影落在哪。这是最容易被写空的一段，也是决定像不像的那一段。
4. **构图**：机位高度、俯仰角、焦段观感、画幅比例、留白在哪。
5. **风格**：饱和度、对比度、整体调性，以及它像哪一类商业图（电商场景图 / 杂志静物 / 生活方式）。
6. **禁止**：这张图里**没有**、也不该出现的东西——文字、水印、人、额外商品、节日元素。

拿不准的不要写。**模型对参考图的猜测一旦写进正文，就会变成下一百张图里的事实**。
材质分不清是树脂还是玻璃，就写「半透明材质，边缘有厚度感」，别替用户认定。

## 第二步：写成模板正文的七节

模板正文是一份技能，固定七节、固定顺序，一节都不许少：

```markdown
## 1. 一句话目标
## 2. 适用场景
## 3. 需要用户提供的输入
## 4. 工作流程
## 5. 输出要求
## 6. 约束与禁忌
## 7. 示例
```

六件事这样落进去：

- 第 1 节：一句话，说清「把素材放进什么场景、出一张什么图」。
- 第 2 节：两三条，什么品类、什么调性的商品适合用它。
- 第 3 节：**素材位**。需要几条素材、各是什么用途，外加可选的比例与保留项。
  这一节是「主体位」的落点：模板只声明需要几条素材，不替用户决定素材本身。
- 第 4 节：编号步骤。把环境、光线、构图三段写死在这里，一步一件事。
- 第 5 节：张数、比例、风格；说清画面里不出现文字水印。
- 第 6 节：禁止项，外加「主体不许被改画」这条硬规矩。
- 第 7 节：两个例子——一个正常请求长什么样，一个越界请求该怎么回。

## 写法纪律

- **先主体后风格**：可换的东西写在前面，氛围词写在后面。商品的形状、颜色、标识属于不可变的那一类，
  必须与光线、道具、情绪分开写。
- **用摄影词，不用形容词**：「柔边椭圆光晕 / 45° 侧顶硬光 / 逆光」有用，「高级感 / 氛围感 / 大片感」没用。
- **改图要说清改什么、保什么**：一句「只改背景」加一份保留清单，比十句形容管用。
- **禁止项要具体**：写「不出现任何文字与水印」，不要写「不要奇怪的东西」。
- **长度**：七节合起来一千字上下够了。写到三千字的模板没人看得懂，模型也只会挑着执行。

写完把正文交给用户过目，**用它出图之前先让他改**——他知道这件商品哪里不能动，你不知道。
