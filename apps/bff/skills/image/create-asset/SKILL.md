# 建素材

素材是「同一个主体的一组图」：一个名字、一种类别（产品 / 人物）、有序的几个视角，第一张是封面。
这条技能只管把用户手上的图变成这样一条素材，不出成品图。

## 收到图先分三种情况

1. **只有一张**：不生成、不补视角，直接进「保存」。一张图也是素材。
2. **多张、明显是同一件东西**：当成一组，按下面的流程走。
3. **多张、看着不是同一件东西**：先澄清——是几件东西各存一条，还是一件东西的多个角度。
   给具体选项，不要问开放式问题。

用户自己已经说清楚了（「这是同一个杯子的三张」「这四张是四个款」），就不要再问一遍。

## 干净视角图默认出拼图

需要补正 / 侧 / 背时，**默认一次出一张拼图**：三个视角横向排在同一张图里，同一光线、同一比例、同一基线。
不要一个视角调一次生图——那样三张的光和比例对不齐，拼不成一套。

拼图用 `editImage`，`imageIds` 第一项是用户给的原图。提示词写到这几点：

- 同一件商品的正面、侧面、背面横向并排，间距均匀，全部完整不被裁切
- 三个视角同一机位高度、同一焦段、同一比例，基线对齐
- 均匀柔光，不留硬阴影；商品的颜色、材质、logo、包装文字一个字都不许改

拆视角时**以这张拼图为基准**，不要回到原图：`editImage` 传拼图，一次要一个视角，
提示词写「只保留正面这一个视角，输出单张」，这样拆出来的几张才是同一套。
拆出来的追加进同一条素材，标 `front` / `side` / `back`；拼图自己也是一个视角，标 `sheet`。

## 透明底还是白底

透明底**只在这一轮钉死的出图模型原生支持透明输出时**才要（gpt-image 系支持，其它多半不支持）。

- 支持：提示词里明确要求透明背景、输出带 alpha 通道的 PNG，保存时背景状态记 `transparent`。
- 不支持：**出纯白背景**，保存时记 `solid`。不要自己抠图，也不要把白底说成透明底。
- 出完拿不准到底透没透：记 `solid`。记错了用户后面套模板时才会发现，那时已经浪费了一次出图。

## 保存

图齐了就调 `saveAsset`，一次把这些交出去：

- `name`：用户说过怎么叫就用他的说法；没说就按「颜色 + 材质 + 品类」起一个短名。
- `kind`：商品 `product`，人 `person`。
- `background`：见上一节。
- `views`：按顺序，第一张是封面（有拼图就拼图当封面）。**用户上传的原图一并带上**，标 `none` 或对得上的视角，`source` 记 `upload`；这一轮生成的记 `generated`。

`saveAsset` 只是把卡片发给用户，**不是保存**。用户在卡片上去掉不要的图、改完名字、按下保存才落库。
所以调完不要说「已保存」，说「卡片发你了，确认一下」。用户保存之后系统会告诉你，那时再往下走。

手上没有存素材这个工具时，别绕路：告诉用户素材库要登录并打开同步才存得下，图先留在画布上。

## 别做的事

- 不要把不同商品塞进同一条素材：一条素材就是一个主体。
- 不要为了凑齐正侧背去编造用户没给过的角度（正面照编不出真实的背面，编出来的是另一件货）。
  只有一张正面照又必须要背面时，先告诉用户这一步是模型的推测。
- 不要在这条技能里出场景图、海报：那是模板的事。
