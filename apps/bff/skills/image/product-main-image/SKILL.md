# 电商主图

> 示例级内容，尚未经过真实投放数据验证；与用户提供的平台规范冲突时一律听平台规范。

主图只有一个任务：**在缩略图尺寸下，让人一眼认出这是什么、好在哪**。别把它当艺术创作。

只调整已有照片的机位 / 朝向时，直接进入「多张已有照片分别调整角度」，沿用原图画幅和背景，不套用新主图的白底、居中或文案默认值。

## 动手前先把这三件拿准

1. **商品本身** —— 用户引用了实拍图吗？没有就先 `readLibrary` 按商品名查一下素材库。
   **有实拍图时一律走 `editImage`，不要 `generateImage`**——主图必须是这件真商品，凭空生成的是另一件货。
   素材库里也没有，才问他有没有实拍图；这是唯一一件你替他补不了的。
2. **平台与画幅** —— 用户没说就按主流电商主图的正方形来；他说了平台就照那个平台的规范走。
3. **底色** —— 白底（平台主图位通常强制）还是场景图（详情页、种草位）。拿不准就先出白底。

**这三件拿得准就直接做**，把你替他定的平台、画幅、底色在回复里说一句，别为了凑齐细节连环追问。
只有「这件商品该往哪个方向拍」本身有两种以上差很远的走法时，才用澄清工具给 2-4 个方向选项让他单选。

## 平台决定文案语言，不用问

用户提了平台，语言就跟着平台走，**不要反过来再问他一次**：

- 淘宝 / 天猫 / 京东 / 拼多多 / 1688 / 小红书 / 抖音 → 中文简体
- Amazon / Temu / Shopee / TikTok Shop / AliExpress / eBay / Lazada / OZON 等跨境平台 → 英文
- 用户明确指定了语种（「淘宝的图但文案用英文」）就听他的
- **他压根没提平台：按中文简体做，不要为这件事发问**，在回复里说一句「按中文简体做的，投跨境的话告诉我平台我重出」

## 白底主图

`editImage`，`imageIds` 第一项是商品实拍图。`prompt` 要写到这几点：

- 纯白背景，无阴影或仅保留一层贴地的柔和投影
- 商品居中，四周留出约 10% 的边距
- 正面或用户指定的角度，主视觉完整不被裁切
- **保留商品本身的一切**：颜色、材质、logo、包装文字、型号标识一个字都不许改

最后一条是这类图最容易翻车的地方：模型很爱「顺手美化」包装上的文字。prompt 里要写死。

## 场景主图

同样走 `editImage`，多写两点：

- 场景要与使用情境一致（厨房用品进厨房，户外装备进户外），不要为了好看放一个商品不可能出现的场景
- 光线方向和商品实拍图一致，否则贴上去像两张图拼的

## 卖点文字

**默认不要在图里生成文字。** 生成的中文字几乎一定会糊、会错、会写出商品没有的承诺。
用户明确要文字时：

- 只放一句短的（不超过 8 个字），放在留白处
- 生成后主动提醒用户「图里的文字请人工核对，模型写的字可能不准确」

## 出几张

- 用户没说张数就出一张。满意再说。
- 用户要「多几个版本挑」时，用 `editImage` 的 `n` 出同一个方案的多版；**不同的方案（白底 vs 场景、不同角度）要分别调用**，不要靠 `n` 一次撞运气。
## 多张已有照片分别调整角度

多张照片分别改角度时，按全局逐张规则各自调用 `editImage`，默认每次只带当前原图。额外参考只在指定或明确委托的用途下加入，并在提示词中说明用途；不能因其它照片也是同一商品就全带上。每个目标默认出一版，用户要求多版时按其数量用 `n`。

提示词先分清相机机位变化、主体自身旋转与裁切 / 透视变化。相机移动时，保留商品身份、场景空间关系、材质和光源方向，允许透视、遮挡与可见区域随之变化；仅保留用户没要求改变的景别、机位高度和画幅。主体旋转则保持相机机位，并说明只改变主体朝向。两者都不擅自增删场景元素。

同一张原图要出多个明确角度时，每个角度从同一张原图分别调用，不在前一个角度的产物上继续叠加。角度有两种以上明显不同的解释时，先给具体选项澄清；意图明确就直接做。

逐张调整已有照片不是设定板流程；需要可复用的角色 / 物品设定图时才加载 `character-sheet`，按用户要求交付拼版或独立视角。

## 用户明说的约束不许静默丢掉


画幅、角度、颜色、必须保留的元素——只要他说了，就照做。
**做不到的先说，不要做完了再补一句「顺便告诉你没满足」**：
比如他要 3:2 而这一路只出得了方图，先说明这一点，问他是接受方图还是自己裁，别默默出一张方图交差。

## 验收

生成完不要说「已完成」。一句话讲清三件事：

1. 你替他定了什么（平台、语言、画幅、底色、张数）
2. 这一批是几次生图
3. 哪里需要他人工确认——特别是商品细节有没有被改动、文字有没有错

工具返回成功只代表出了候选，不代表这张图能直接上架。
