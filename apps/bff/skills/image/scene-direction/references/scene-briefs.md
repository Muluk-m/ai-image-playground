# 场景简报示例

这些示例展示如何从一句需求里选**一个**视觉关系，不是给所有场景固定放窗、雨、蒸汽或石阶。用户说了具体机位、光线、元素时，以用户原话为准。

## 从零生成：雨夜街角的旧书店

用户只说「画一家雨夜的旧书店」时，可把“书店的暖光照到湿街面”作为唯一画面事件：

```text
主体：街角一间营业中的旧书店，透过橱窗看得见书架，不出现人物
场景与画面事件：雨停不久的窄街，橱窗暖光在门前湿石板上形成一条反射，反射把视线引向店门
构图：从街对面略低机位斜看，左下角一小段模糊的墙沿作前景，书店在中景偏右，远处街道渐暗；上方留安静的夜色
光线与配色：橱窗是唯一暖光源，街道为深蓝灰，门口反射为暗琥珀色；阴影与反射方向一致
材质与细节：旧木门边缘磨损、玻璃上的少量雨痕、湿石板的断续反光
约束：不要行人、车辆、霓虹招牌、可读店名或水印
```

## 带真实素材：桌灯进入使用场景

用户给了桌灯实拍图，想要“更有生活气息的书房场景”时，以实拍图为 `editImage.imageIds[0]`。场景事件是“灯照亮正在翻开的书”，不需要额外人物：

```text
只重设计桌灯周围的环境：把它放在深色木书桌左侧，灯光照亮桌面中间摊开的书页；桌沿从左下向中景延伸，后方书架低对比、部分遮挡。
保留第一张图中桌灯的灯罩形状、灯臂结构、颜色、材质、标识与比例；灯的光色与书页和桌面上的投影一致。不要改变灯的设计，不增加人物、第二盏灯或文字。
```

如果用户说的是“灯完全不动，只换背景”，转 `scene-swap`，不改变灯在画面中的位置和机位。

## 风格化场景：海岸步道

用户说「海边有点孤独但别太丧」时，可让空旷的步道通往远处唯一的小亭，靠尺度关系表达安静，不凭空添加孤独的人：

```text
主体：通往海边的小亭与一段无人步道
场景与画面事件：步道由近处向右侧远处的小亭收束，海平线留出宽阔安静区域
构图：略高机位，近处步道石纹清楚，中段海草被风压向同一方向，远处小亭轮廓简洁；小亭只占画面一小部分
光线与配色：多云午后的一侧柔光，灰蓝海面、浅沙色步道、少量褪色绿色海草
材质与细节：步道边缘被海风磨损，海草的方向与风一致
约束：不加人物、巨大月亮、发光粒子、诗句或水印；不要把画面压成暗黑恐怖色调
```
