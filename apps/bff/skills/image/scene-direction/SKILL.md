# 场景设计

场景不是把主体放在一张漂亮背景前。让主体与环境发生一个看得见的关系：光照到它、风推动它、道路引向它，或它改变周围的尺度与秩序。**一次只选一个主关系**，其余元素为它服务。

## 先划清任务边界

- 用户已有图，只要求保留主体位置与机位、换掉背景：改用 `scene-swap`。
- 用户要电商平台主图：改用 `product-main-image`；要带标题文案的海报：改用 `poster`。
- 用户给的是写好的完整提示词、要求直出：原文交给 `generateImage`，不套本技能的构图方法。用户明确要优化才重写。
- 用户要重新设计整张场景：继续。没有输入图用 `generateImage`；有必须保留的真实人物或商品图用 `editImage`，第一张是编辑目标，其他图只有被明确指定为参考时才加入。
- 用户指的是某件真实商品或某个人，却没给图：先用 `readLibrary` 找素材；找不到就请他提供，不凭名字编造外形。

## 拟一张场景卡，再写提示词

从用户原话和实际图片里分清**不可改**与**可设计**。在心里填这六项，不用把表格展示给用户：

1. **主体**：谁或什么是主角，哪些外形、身份、颜色、标识必须保留。真人与商品的识别特征不能用氛围词盖掉。
2. **地点与用途**：画面在哪、给谁看；室内外、尺度、季节和时间只取用户给的或场景合理需要的。
3. **一个画面事件**：主体和环境的可见关系。优先从物理作用或使用情境里找，例如灯照亮桌面、雨水映出门口的光；不要凭空添人、动物、品牌或戏剧情节。
4. **焦点与路径**：观众第一眼看哪里，视线沿什么线条进入；背景哪些区域要安静。
5. **镜头与空间**：景别、机位高度、朝向，近处、中段、远处怎样拉开。不是每张都塞满三层，但至少避免主体与背景处在同一平面。
6. **光与色**：一个能在画面里找到来源的主光，落到主体和环境的方向一致；2–3 个有主次的颜色，亮色只放在焦点或引导线上。

## 让画面活起来

选择**一种**组织方式，按内容决定，别轮流机械套模板：

| 场景条件 | 可用的组织方式 | 要看见的结果 |
| --- | --- | --- |
| 有门、窗、树枝或街角 | 借前景形成入口 | 前景只占边缘，中景主体完整，远景交代地点 |
| 有路、桌沿、河岸或光束 | 用方向线引向主体 | 视线走进画面，而不是停在正中央 |
| 主体很小、环境很大 | 留出一块安静区域 | 尺度关系成为主题，空处有明确形状 |
| 主体有动作或功能 | 抓动作将要发生或刚发生的一刻 | 风、蒸汽、水迹、投影等只留一种可读线索 |
| 画面需要强图形感 | 用形状或明暗形成一次对比 | 焦点与环境相互呼应，不靠一堆装饰争注意力 |

默认的“主体居中 + 两侧均匀摆道具 + 背景虚化”很容易呆板。只有用户明确要目录照、对称建筑或正面展示时才这么做。道具不超过完成场景所需的数量；每添一件都要回答它如何解释地点、尺度、动作或光线。回答不了就删。

**具体但克制**：写出一块磨损的石阶、一束从左窗照进来的侧光，比罗列十种材质有用。用遮挡、透视、尺寸梯度与接触阴影建立空间；不靠“电影感”“高级感”“氛围感”替代画面决定。写实场景要有可信的重力、反射与使用痕迹；风格化场景仍要有清楚的空间与焦点。

## 交给图片工具

**从零生成**：把场景卡压成逐行简报交给 `generateImage`。只写用户要求和最终能看见的东西，不写分析过程：

```text
用途：<画面要用在哪；用户没说可省略>
主体：<主角与必须可见的状态>
场景与画面事件：<地点，以及主体与环境的一个关系>
构图：<焦点位置、机位、近远层次、安静区域>
光线与配色：<主光来源、阴影方向、主色与点睛色>
材质与细节：<两三处能支撑场景可信度的细节>
约束：<用户的保留项、禁忌；无多余文字、水印与无关 logo>
```

**基于现有图**：`editImage` 的 `imageIds` 第一项放用户要改的图。提示词先写“把什么场景关系改成什么”，再写“保留什么”：主体身份、外形、材质、颜色、标识，以及用户要求保留的姿态和构图。允许重构的范围要说清楚；不要声称生成式改图能保证原照片像素不变。有选区时按工具要求带 `selectionBindings`，选区之外不主动改。若用户提到库里的素材却没引用，先用 `readLibrary` 找到它。

用户没要求多张就出一张。同一设计方向的多版用 `n`；要比较不同机位或不同场景关系，分别拟简报，不把互相冲突的方向塞进同一个 `n`。用户指定画幅、参考图、颜色或排除项时，它们高于本技能的默认组织方式。

## 提交前自检

- 缩小看，是否一眼看出主角与一个视觉焦点？
- 遮住主体，环境是否仍在解释地点与事件，而非任意图库背景？
- 主体与环境是否共享光源、透视、尺度和接触关系？
- 有没有无来源的漂浮物、均匀撒满的道具、无意义的发光边、凭空加的人或文字？
- 与用户原图比，哪些特征必须保留，提示词是否逐项点明？

不满足就**先改简报**，不要把“更有设计感”附在原提示词末尾。用户要的确实是平静、对称或极简场景时，尊重他的方向，不强行制造戏剧性。

提交前用一句话说清你选的画面事件、机位与光线，用户可在拟稿卡片里改。用户要具体参考时，`references/scene-briefs.md` 有三种场景简报；只借组织方式，不把示例里的物件带进用户的画面。
