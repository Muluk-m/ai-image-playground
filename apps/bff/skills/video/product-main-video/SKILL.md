# 电商主图视频

> 示例级内容，尚未经过真实投放数据验证；与用户提供的平台规范冲突时一律听平台规范。

主图视频挂在商品详情页的第一屏，用户是**边划边看、没有声音**的。所以它只有一个任务：
**在几秒内把「这是什么、长什么样、怎么用」说清楚**。不要故事，不要转场炫技，不要片头片尾。

这是一条场景型技能：**意图清楚就一次做到位**，不要先出一份分镜表让用户审。

## 先把这五件替他定下来

1. **商品图** —— 用户引用了实拍图吗？没有就 `readLibrary` 按商品名查素材库。
   **有实拍图时首帧一律走 `editImage` 从它改出来，不要 `generateImage` 凭空画**——
   主图视频里必须是这件真商品。**用户本轮请求指向一件真实在售商品时**，素材库也没有才问他要图，这是唯一你补不了的一件；
   主体是虚构或创意形象（吉祥物、插画角色、概念品）就不要问，直接 `generateImage` 画首帧。
2. **画幅** —— 用户没说：商品主图位按 `1:1`，短视频位按 `9:16`。说了就照他说的。
3. **时长** —— 用户没说就挑最短的那一档（几秒足够把商品说清楚）。要更完整的演示就往上挑一档。
   `durationSeconds` 能填哪些看它的参数说明，那是这个部署当前那个视频模型真支持的档位；
   用户明说的时长它给不了时，工具不会提交，会回一段「它支持哪些」，照那段话跟他确认再重试。
4. **平台与语言** —— 淘宝 / 天猫 / 京东 / 拼多多 / 1688 / 小红书 / 抖音 → 中文简体；
   Amazon / Temu / Shopee / TikTok Shop / AliExpress 等跨境 → 英文。
   **没提平台就按中文简体做并说明**，不要为这件事发问。
5. **走哪一种** —— 见下一节。

这五件拿得准就直接做，把你替他定的写在回复里。
只有「这条片子该展示什么」有两种以上差很远的走法时，才调澄清工具给 2-4 个具体选项。

## 三种走法，挑一种

| 走法 | 适合 | 镜头动作 |
| --- | --- | --- |
| **环绕展示** | 外观就是卖点（鞋、包、家电、瓶装） | 镜头绕商品半圈，商品静止 |
| **细节推近** | 做工材质是卖点（面料、五金、刀刃） | 镜头从全貌缓慢推到细节处 |
| **使用演示** | 会用才知道好（厨具、工具、美妆） | 一双手完成一个完整动作 |

用户没说就按商品类别挑一种，在回复里说明你选了哪种、为什么。
他要「三种都看看」时分别调用 `generateVideo`，一种一次。

## 第一步：出首帧

`editImage`，`imageIds` 第一项是商品实拍图，`n` 保持 1。`prompt` 写四件事：

1. 画幅与构图：商品居中、完整不被裁切、四周留约 10% 边距
2. 背景：白底或与商品匹配的简洁场景，不要抢戏
3. 光线：干净的棚拍光，商品的材质与颜色如实呈现
4. 保留清单：颜色、材质、logo、包装文字、型号标识一个字都不许改

商品实拍图本身就干净、可以直接当首帧时**跳过这一步**，直接用它的图片 id，省一次生图。
在回复里说一句你省了这一步。

## 第二步：出片

`generateVideo`：

- `imageId` 填首帧的图片 id
- `prompt` **只写动作与镜头**，不要重复描述首帧里已经有的静态画面。一句话最多三件事：
  主体怎么动 → 镜头怎么动 → 环境细节（光斑流动、蒸汽上升之类；没有就别硬加）
- `durationSeconds` 照上面定的
- `aspectRatio` 填定下来的那个
- `resolution` 只在用户说过时才填
- 除了首帧还有商品细节图（背面、logo 特写）要保持一致时，放进 `referenceImageIds`，在 `prompt` 里点名「图片 1」是什么；当前模型不支持参考图时工具会拒绝并说明，照实告诉用户

几种走法各出一条是给用户挑的备选，**不要排进一条时间线**。

prompt 例子：

- `镜头绕着产品环绕半圈，产品保持静止，背景光斑缓慢流动`
- `镜头从全貌缓慢推近到表带扣处，产品静止不动`
- `一双手把咖啡粉倒入滤杯并注水，镜头固定，热气升起`

## 不要做的事

- **不要往视频里放文字与价格。** 模型写的字会糊会错，主图位的文案由平台自己的组件叠。
- **不要加片头片尾、转场特效、logo 动画。** 主图位只给几秒，全用来看商品。
- **不要让商品在动的过程中变形或换色。** prompt 里写死「产品外观保持不变」。
- **不要承诺配音、字幕或背景音乐**——这一路出不了这些。用户要，就实话告诉他成片是无声画面。

## 用户明说的约束不许静默丢掉

他说了 9:16 就填 `aspectRatio: '9:16'`；`aspectRatio` 只有 `16:9` / `9:16` / `1:1`。
他要 4:5、3:4 这类平台常见比例，**先说做不到、给出最接近的替代，等他定了再动手**，
不要默默出一条再补一句「导出时自己裁」。时长同理。

## 交付

一次说完：你替他定了什么（走法、画幅、时长、平台语言）、这一批是几次生图几次生视频、
以及要他确认的地方——商品有没有变形、颜色与 logo 对不对、有没有冒出多余文字。
再给 1-2 个具体的下一步：换一种走法出一版 / 出个 9:16 的版本投短视频位 / 配一套主图。

用户一次要多条（多个商品、多种走法）时**一次做完**，不要做完第一条就停下来问要不要继续；
他中途喊停就停，剩下的不要自作主张跑完。
