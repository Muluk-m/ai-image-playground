# 种草视频

> 示例级内容，尚未经过真实投放数据验证。

种草视频和主图视频的差别在**谁在说话**：主图视频是商品自己在展示，种草视频是**有个人在推荐**。
所以它一定有生活感、有使用场景、有「我为什么要买」。

这是一条场景型技能：**意图清楚就一次做到位**，不要先出一份分镜表让用户审。

## 先把这五件替他定下来

1. **商品图** —— 有实拍图就 `readLibrary` 查出来 / 用用户引用的那张，首帧从它 `editImage` 改出；
   没有实拍图才问他要，这是唯一你补不了的一件。
2. **走口播还是走生活场景** —— 见下一节。用户没说就按商品类别挑一种并说明。
3. **画幅** —— 用户没说一律 `9:16`。小红书、抖音、TikTok 都是竖屏，这个默认值不用问。
4. **时长** —— 用户没说就挑一个装得下一个完整动作的档（8 秒上下）。`durationSeconds` 能填哪些看它的
   参数说明，那是这个部署当前那个视频模型真支持的档位。要更长就往上挑一档，别把两段短的当长的用。
5. **语言** —— 小红书 / 抖音 / 淘宝 / 京东 / 拼多多 → 中文简体；
   TikTok Shop / Amazon / Temu / Shopee 等跨境 → 英文。**没提平台就按中文简体做并说明**。

只有「这条片子该怎么种草」有两种以上差很远的走法时，才调澄清工具给 2-4 个具体选项让他单选。

## 两种走法

### A. 口播

一个人对着镜头讲。适合功效类、需要解释的商品（美妆、保健、数码、课程）。

- **首帧**：`generateImage` 画一个符合目标人群的人，手持或身旁放着商品，正对镜头，
  生活化的室内背景（卧室、梳妆台、书桌），自然光。
  用户给了人物设定图 / 出镜人照片时，改成 `editImage` 从那张出发。
- **出片 prompt**：`人物对着镜头自然讲话，手中商品轻微展示，镜头固定微微手持感`。
- **文案交付在文字里，不在视频里。** 见下面「配音与字幕」。

### B. 生活场景

不出镜，只拍使用瞬间。适合家居、厨房、服饰、宠物、食品。

- **首帧**：从商品实拍图 `editImage` 改出一张真实使用场景（厨房台面、床头柜、玄关），
  光线是自然的室内光，不是棚拍光。
- **出片 prompt**：一双手完成一个完整动作 + 镜头怎么动，例如
  `一双手把香薰点燃并放回床头柜，镜头缓慢推近，烛光摇曳`。

## 配音与字幕：两件独立的事，而且这里都做不了

这一路的 `generateVideo` **产不出配音，也烧不进字幕**。不要承诺，不要假装做到了。

正确做法是两件事分开交付：

1. **口播文案**：写在回复的文字里，一条一行，直接能拿去录。
   口播走法必须给；生活场景走法按需给。
2. **字幕文案**：同样写在回复里，按镜标好时间点，让用户在剪辑软件里自己叠。

在回复里说明一句：成片是**无声画面**，配音与字幕请用户自行叠加。
用户明确要「带配音的成片」时，先说这件事做不到、给出「画面 + 文案稿」这个替代，再动手。

## 出片

`generateVideo`：

- `imageId` 填首帧的图片 id
- `prompt` 只写动作与镜头，不要重复描述首帧里已有的静态画面
- `durationSeconds`、`aspectRatio` 照上面定的；`resolution` 只在用户说过时才填

一条装不下的内容（开箱 + 使用 + 效果）就拆成 2-3 段，**每段各自 `generateVideo`**，
并在回复里说清这几段要用户自己接成一条——我们没有拼接工具。

## 用户明说的约束不许静默丢掉

画幅、清晰度与时长能取哪些值，看 `generateVideo` 那三个参数各自的说明——写的是这个部署当前
那个视频模型真支持的那几个。用户要的值不在其中（4:5、30 秒），**先说做不到、给出最接近的替代，
等他定了再动手**。不要默默出一条再补一句「你可以自己裁 / 自己接」。真填了做不到的值，工具会拦下来
不提交并回一段「它支持哪些」，照那段话如实转达，不要当成已经出片。

## 首帧必须是一个真画面

三视图、设定图、拼图这类参考图不能直接当 `imageId`——出来的片子就是一张拼图在动。
有设定图时先 `editImage` 把它变成单一视角的完整画面，再拿那张当首帧。

## 交付

一次说完：走了哪一种、你替他定了什么（画幅、时长、平台语言）、
这一批是几次生图几次生视频、口播与字幕文案（逐条列出）、
以及那句实话——成片无声，配音字幕自行叠加。
再给 1-2 个具体的下一步：换另一种走法出一版 / 补一段效果展示 / 按这条配一套图。

多段都跑完之后**在同一轮里把交付做完**，不要停在最后一段问「要我继续吗」。
用户中途喊停就停，剩下的不要自作主张跑完。
