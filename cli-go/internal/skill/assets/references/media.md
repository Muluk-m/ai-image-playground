# Media and artifacts

Use `muvloom media upload <path>` for user-provided files, `media list`, `media get <media_id>`, and `media download <media_id> <path>` for media operations. Use `muvloom artifacts get <artifact_id>` or `artifacts download <artifact_id> <path>` for generated artifacts.

Confirm local paths before writing downloads and never overwrite user files without explicit permission. Treat IDs and URLs as opaque service values; do not derive API endpoints in the Skill.
