# 2026-09-29 调用栈溢出检查

基线：`49c3df8`（参考图文件头正则修复 #908 之后）。

## 范围与方法

- 对 `apps/`、`packages/`、`private/apps/` 的 832 个非测试 JS/TS 源文件做语法树扫描，检查正则、函数调用的参数展开与自调用候选；不包含第三方依赖内部实现。
- 沿图片导入、压缩、BYOK/BFF 提交、结果恢复、画布几何、工具箱、历史分组和配置导入核对调用入口与数量限制。
- 对可疑点先运行失败用例，再修改；用实际浏览器验证修复后的模块。所有上游请求使用本地桩，不消耗生成积分。
- 这是特定风险类别的静态检查与定向压力验证，不代表所有输入、设备和依赖都不会出现栈溢出或内存不足。

## 已复现并修复

| 位置 | 触发条件与证据 | 修复 |
| --- | --- | --- |
| `openaiCompatibleImageApi.ts` 的通配结果路径 | 实际 `getCustomQueuedImageResult` 入口读取含 150,000 项的数组或对象，两者都在 `next.push(...values)` 抛出同样的 RangeError | 逐项追加，保留路径顺序与空值过滤 |
| 同文件的请求模板解析 | 兼容适配器直接处理 4,000 层嵌套模板，在递归解析时溢出，请求尚未发送 | 限制解析深度为 64，过深时给出可操作的中英文错误 |
| 工具箱长图/拼图布局 | 150,000 项尺寸列表在 `Math.min(...sizes)` 溢出 | 使用累积最小值；普通尺寸、间隔和排序语义不变 |

上述规模是稳定触发的压力样本，不是通用浏览器阈值，也不是已收到的用户生产事故数量。
当前 `callImageApi` 不传自定义 provider 给兼容适配器；通配结果提取仍由旧自定义异步任务恢复路径使用。
过深请求模板属于保留兼容能力的防御性修复，不能算作已确认的当前内置生成故障。

历史分组最新时间、文件夹批次追加和模板引用最大序号也去掉了无上限参数展开。
这些是相同模式的预防性修改，未声称存在对应的真实用户事故。

## 已核对的其他位置

| 类别 | 结果 |
| --- | --- |
| 其他 data URL 正则（Gemini、同步、BFF 输入/归档/输出、模型参考图） | 对源码提取的正则使用 32 MiB Base64 输入，在 Node 24 与 Bun 中未复现；没有再发现 #908 的无上限 Base64 字符类量词 |
| 二进制转 Base64 | `bytesToDataUrl` 已按 32,768 字节分块；项目地址编码固定 16 字节 |
| 画布几何 | 旋转包围框只展开 4 个角；本地自由画笔通过循环计算；云端 schema 限制 1,000 个元素、20,000 个坐标值（横坐标至多 10,000 项） |
| 智能体画布整理/占位 | 整理输入上限 200 项；占位受任务输出数量限制 |
| IndexedDB 领养 | 记录迁移先分批，再追加结果 |
| 文件夹递归、提交确认和启动重试 | 文件读取先经过异步边界；确认与重试从后续用户事件重新进入，不累计同步栈 |
| 比例计算 GCD | 递归前有有限正数/整数检查；不是无终止条件的任意对象遍历 |
| 提示词 DOM | 粘贴路径读纯文本并由组件重建节点；未找到任意深 HTML 直接进入遍历的入口 |
| 服务端 HTML/命令正则 | 2 MiB 表格分隔符、实体和 slash-command 样本在生产运行时 Bun 中均通过 |
| 服务端 canonical JSON/参数 | Node 的 4,000 层函数探针会溢出，Bun 同样本未复现；队列 HTTP 请求 schema 为限定结构。没有据此改动生产序列化契约，也不将这次探针视为任意深度安全保证 |

## 验证

修复前：两个大响应测试、深模板测试和大批量布局测试共 4 个失败，均出现
`Maximum call stack size exceeded`；正常嵌套模板对照通过。

修复后：

- 自定义接口边界、工具箱布局、API 和语料一致性：4 个文件，74 个测试通过。
- 文件夹导入、模板引用和历史分组：3 个文件，27 个测试通过。
- Chromium 152：数组/对象大响应均提取到目标图片；深模板明确拒绝且发送请求数为 0；大批量竖拼、横拼、宫格布局尺寸均正确。
- 本机仅运行指定用例、单 worker；远端 `rmake --doctor` 连接超时，全量 lint/typecheck/build/test 交 PR 与 main CI。

压力布局验证的是尺寸计算；没有分配 150,000 张位图或超限输出画布。实际输出仍受现有画布尺寸/面积门禁约束。
