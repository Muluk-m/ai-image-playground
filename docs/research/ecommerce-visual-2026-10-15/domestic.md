# 电商视觉国内竞品能力核查

核查日期：2026-10-15（Asia/Taipei）。范围：美图设计室、稿定、绘蛙、飞象、万相营造；附京东羚珑的平台替代线索。只读公开网页与公开界面；没有上传商品、消耗额度、创建账号或验证生成质量。未修改产品代码；本文件为调研附件。

## 证据规则

- **D：官方教程/功能说明明示**，通常有输入、步骤、输出或限制；不等于实际输出达到宣传效果。
- **P：官方产品页/公开菜单明示**，说明有此入口或产品承诺；不推断稳定性。
- **U：本次真实浏览器可见入口/界面**，仍未生成或下载结果。
- **H：较旧的官方教程**，仅作历史能力证据，数量/套餐不可当现行承诺。
- **?：本次未确认**，不表示不存在。
- “文字可改”“有编辑器”“有图层”不能推出任意 AI 生成图片都能拆成可编辑图层；“平台适配”不能推出直接上架/API 同步；“保真”宣传不能推出有自动商品一致性 QA。

## 核心结论

1. **国内通用电商视觉的功能基线已明显超过生成与换背景**：抠图修边、白底/透明导出、清晰度、消除/局部修补、改尺寸、可改文字和模板、主图/场景/卖点/详情、批量处理至少应进入我方缺口核对。
2. **套图、A+、参考复刻、商品替换、品牌复用、团队共享均已有明确竞争者**，不能作为“我方独有”宣传。
3. 美图最适合对标完整交付链；稿定适合对标编辑器、模板和多节点工作流；绘蛙适合对标服饰保真修补与投前检查；飞象适合对标跨境语言/平台结构；万相营造体现平台内工具的替代压力。
4. 只根据这次能力研究，优先级应先保基本图片加工和交付，再完善套图/详情任务结构与单张改稿，再按真实客群选择跨境或服饰深度；不应把服饰、跨境、大型团队/平台接入一概归为所有用户的 P0。

## 产品核查要点与边界

### 美图设计室：最完整的基线参考

| 流程 | 官方说明与限制 |
|---|---|
| 抠图到交付 | 单图或最多30图/文件夹；透明PNG/白底；智能区域、擦除恢复、羽化和投影可调。实际发丝、透明商品质量未测。(M1) |
| 套图 | 同商品最多6张原图；设平台、地区、语言、比例，填写卖点；自动或自定义图种。页面“自定义至少7张”与例子“5–7张”口径不同，应以运行界面为准。(M2) |
| A+/详情 | 16种模块选择，含卖点、场景、细节、参数、配件、品牌等；普通/高级A+及通用比例；可单模块重做。平台“规范”是生成定位，未证明自动审核合规。(M3) |
| 多商品复用 | 批量明确覆盖爆款参考复刻与服饰套图；即刻/夜间两模式。历史可勾选下载、二次改图与商品还原；当前文档称还原5次免费，后续耗豆。(M8) |
| 图层/模板 | 模板内文字/图片可绑定标签，批量生成多页；这证明模板数据替换，不代表生成的成品自动分层。(M4) |
| 品牌 | Logo、色卡、文字样式由所有者/管理员管理，成员应用；团队付费能力，到期保留但不可设置/应用。(M9) |
| 费用边界 | AI按美豆计费，会员额度用完需额外购买；批量文档标高级模式15豆/张、常见7张105豆、夜间8折和最多50任务并行；商品数上限按实时UI。不可把会员当无限生成。(M8) |

## 给主报告的优先级输入（非我方缺口结论）

- **P0候选：** 真透明/白底导出、修边与局部可控修改、尺寸/清晰度/格式、可靠保存/下载；用户无需理解提示词才能找到常用任务。必须结合我方代码与真实行为确认是否缺口。
- **P1候选：** 商品资料+多角度输入、结构化套图/详情模块、同套视觉要求、单张/单模块重试、可改文字与商品还原；小批量任务与有组织的导出。美图是明确参照。
- **按客群提升为P1或留P2：** 图片翻译/A+（跨境）、试穿/印花修复（服饰）、多商品规模批量（高频铺货）。
- **P2候选：** 品牌库、团队审核/共享与质量检查；不应把有品牌库本身宣传为独有。
- **P3候选：** 全平台直连上架、重型DAM/企业权限、大规模夜间托管、复杂短视频链路；有真实用户需求才扩大。
- 更可能形成有效优势的是 **同商品关键结构/文字保护、局部改稿保持已确认内容、整套产物校验与省返工证据**；竞品已有相近入口，必须同题测评才能主张更好。
