# 国内视频剧本与漫剧制作竞品：垂直产品一手证据

调研日：2026-10-01。范围是故事/剧本、角色资产、分镜、生成片段、继续制作的资源交接。排除传统剪辑软件及仅提供单次视频生成的产品。搜索引擎只作发现入口，以下事实均来自产品自己的站点、文档或源码。没有注册、付费生成、安装这些产品，因此不宣称生成质量、完整流程已实测或市场份额。

证据等级：**A 源码**＝可定位到实现，尚未运行；**B 操作文档**＝官方提供具体步骤，尚未实操；**C 官方展示**＝官网自述，不能替代验收；**未知**＝本轮没有足够证据，不等于不存在。中文市场相关性不等于已核验经营主体；开源项目与成熟商业 SaaS 分开看。

## 应重点对照的四个产品

### 1. LibTV（哩布哩布）：对话与项目画布可以是同一份项目的两个入口

- **定位与形态（C）**：官网是专业视频创作工具，公开首页提供项目、资产、画布创作、LibTV Agent，以及剧本原创与改编、角色造型室、导演执导入口。它与本项目的“在已有创作站中增加故事制作模式”直接重叠。[官网](https://www.liblib.tv/)
- **可核验链路（B/A 文档及工具源码）**：官方技能仓库支持创建会话、向同一会话追加创作消息、上传参考图片/视频、查询进度；响应同时提供 `sessionId`、`projectUuid` 和项目画布 URL。可将会话产出的图片/视频批量下载。这里能确认的是“对话—项目—媒体结果”贯通，不能据此断言每一步都采用固定向导。[官方技能仓库](https://github.com/libtv-labs/libtv-skills)
- **剧本局部修改、镜头候选、角色三视图**：本轮未取得官方细节教程；不要把导航站的三视图/宫格/节点描述当实测。
- **导出粒度（B）**：官方脚本批量下载会话中的图片与视频，并支持指定输出目录和文件名前缀；未证实结构化剧本、角色表、镜头关系一并 ZIP 导出。[下载脚本文档](https://github.com/libtv-labs/libtv-skills#下载结果)
- **价格门槛（C）**：本轮首页显示年会员促销和 Seedance 2.0 720P 低至 0.46 元/秒，仅能视为特定促销口径，不可拿来当平均成片成本；Agent 是否独立计费、首充、失败重试计费未核验。[官网价格展示](https://www.liblib.tv/)
- **推论**：单纯宣称“用对话生成视频”已经不构成明显差异。Muvloom 需要回答用户为何更容易定位一镜、修改一镜、选定版本、交接资源。

### 2. 魔因漫创（Moyin Creator）：结构化分镜及素材包已有源码级参照

- **用户与完整流程（B）**：面向 AI 短剧、动漫与预告片创作者；官方教程允许导入或 AI 创作剧本，然后校准场景/分镜/角色，按需生成资产，再加载分镜到导演板块，微调首尾帧与视频提示词，单镜或合并生成图片，批量生成视频。角色/场景图并非强制独立步骤；不同板块可独立组合。[官方工作流教程](https://github.com/MemeCalculate/moyin-creator/blob/main/docs/WORKFLOW_GUIDE.md)
- **剧本与镜头可控性（B）**：教程明确每个分镜的提示词、首帧、尾帧及运动/时长/风格可调；本轮未核验对话局部改写剧本与候选版本的具体 UI。[同一教程](https://github.com/MemeCalculate/moyin-creator/blob/main/docs/WORKFLOW_GUIDE.md)
- **角色三视图（A）**：生成面板第 71 行存在默认启用的 `three-view` 配置，提示包括正面、侧面、背面；参考图与身份描述也参与角色生成。它证明专门三视图能力进入了产品配置，不能证明输出稳定性。[角色生成源码](https://github.com/MemeCalculate/moyin-creator/blob/main/src/components/panels/characters/generation-panel.tsx#L71)
- **导出粒度（A）**：素材包面板可选图片/视频，支持选择文件夹导出或逐个下载；导演导出统计包括首帧、视频及尾帧。导出服务写入 `manifest.json`，并分别下载媒体。不能将其描述为已经支持剪映工程或 ZIP。[导出面板](https://github.com/MemeCalculate/moyin-creator/blob/main/src/components/panels/script/export-panel.tsx#L117)、[导演导出](https://github.com/MemeCalculate/moyin-creator/blob/main/src/components/panels/export/index.tsx#L374)、[导出服务](https://github.com/MemeCalculate/moyin-creator/blob/main/src/lib/script/export-service.ts)
- **使用门槛（B）**：需配置上游服务商 API、功能对应模型、图床；平台开源不代表模型调用免费。没有统一可比订阅价格。[官方教程](https://github.com/MemeCalculate/moyin-creator/blob/main/docs/WORKFLOW_GUIDE.md)
- **推论**：用户想要的“剧本到分镜到资源包”已有直接产品参照。可以借鉴清晰的制作对象及按镜头编号导出，而不是把整段对话导出成一份聊天记录。

### 3. ArcReel：中文创作生态中的开源近场竞品，直接覆盖对话编排和剪映交接

- **定位与链路（C）**：官网定位 AI 短剧/漫剧工作台；原文进入资产库、分集、结构化剧本、角色设计与分镜、视频合成，Agent 编排。面向有自部署能力的个人和团队，与零配置 SaaS 的使用门槛不同。[官网](https://arc-reel.com/zh/)
- **剧本局部修改与候选（B/C）**：文档区分当前、过期、缺失、阻塞产物；相关输入改变后旧产物仍可预览和导出，默认批量只补缺失，明确选择镜头才刷新。多宫格先审阅再切分，旧分镜保留版本可回滚；官网展示版本并排对比能力。[创作流程](https://docs.arc-reel.com/guide/workflows/)、[版本展示](https://arc-reel.com/zh/)
- **角色资产（B）**：角色、场景、道具作为持续引用的资产；可选分镜图生视频或直接参考生视频。三视图专门按钮未核验。[流程与模式](https://docs.arc-reel.com/guide/workflows/)
- **导出（B）**：官方逐步教程支持按集导出大陆版剪映 5.x/6+ 草稿 ZIP，包括草稿 JSON 和视频 assets；所选 TTS、字幕随模式加入。只包含已成功片段，版本须匹配；CapCut 兼容性未验证。导出用已选视频版本，并按媒体实际长度组织轨道。[剪映草稿导出教程](https://docs.arc-reel.com/guide/jianying-export/)
- **计费与门槛（B/C）**：开源自部署，需要 Docker 和模型凭据；上游 API 付费，文档列生成前费用预估与生成后调用记录；商业版仍处需求登记状态。[入门教程](https://docs.arc-reel.com/guide/getting-started/)、[官网](https://arc-reel.com/zh/)
- **推论**：ZIP 不是一句泛化的“以后可导出”：需要先决定它交付通用素材关系，还是特定剪映草稿。先保留一份稳定的已选版本清单，两种导出才不会拿到不同作品。

### 4. 万兴剧厂：真正同赛道的商业平台，但本轮细节证据不完整

- **已确认定位（C）**：官方站点元数据明确小说 IP 改编、剧本拆解、角色一致性、动态漫及画面/配音/音效协同；创作入口区分 AI 短剧和 AI 剧本，支持小说上传。[官网](https://www.reelmate.cn/)、[创作入口](https://www.reelmate.cn/create/text-to-video)
- **官网真实性（C）**：其用户协议明确 `reelmate.cn` 为万兴科技（湖南）有限公司及关联公司运营。[产品用户协议](https://www.reelmate.cn/products/policies/terms-of-use.html)
- **教程入口（已定位，正文未读到）**：官网 `create-guide.html` 嵌入官方飞书手册。当前抓取未能读取飞书正文。[官方手册入口](https://www.reelmate.cn/create-guide.html)、[手册目标](https://reelmate.feishu.cn/wiki/O68WwmNKIiRTEjkrkHWcEwX8nYf)
- **未知项**：剧本局部重写、多视图流程、镜头候选保存、资产包/工程导出、具体订阅和扣费规则都需进一步官方教程或登录观察。外部文章的“80%可用率”“55%成本下降”等没有采用。
- **推论**：应纳入后续同题实操样本，但不能仅凭产品定位给它填满功能矩阵。

## 给产品讨论的三个证据支持的修正

1. **对话本身不是差异点。** LibTV 和 ArcReel 都已将会话与制作项目关联；需对比的是修改能否准确落到一个角色/镜头，以及回看、选版、继续做是否明确。
2. **三视图既不能凭空砍掉，也不宜固定强制。** 魔因已有专用三视图，同时允许资产环节可选；应按角色驱动剧情与其他任务分别观察，而不是先凭通用生视频经验定交互。
3. **通用素材包与剪映草稿要拆开定义。** 魔因给出素材+manifest 的实现，ArcReel 给出按集草稿 ZIP 的具体交接流程。下一步宜用同一个短剧样本，核验“只重做第二镜—保留旧版—选新版—导出”的真实操作成本，再定我们的第一版。
