# 国内视频脚本与短剧创作竞品：对话、资产、分镜与资源交接

研究日期：2026-10-01（Asia/Shanghai）。本报告纠正上一轮以国外通用创作工具为主的样本选择。目标用户工作是“讨论故事 → 剧本 → 角色/场景参考 → 分镜 → 选镜生成片段 → 带走继续制作”。Adobe 不属于本次核心竞品；剪辑软件只可能是交付目的地。

## 1. 先按用户任务选竞品

入选条件：面向中文/国内创作者，实际覆盖剧本、角色资产、分镜、视频生成中的连续环节；有能追到厂商的产品入口、操作文档或源码。仅提供底层视频模型、剪辑器、图片工具或泛化营销落地页，不进入核心比较。

| 研究优先级 | 产品 | 为什么对标 | 证据与边界 |
| --- | --- | --- | --- |
| 第一组：最贴近需求 | **小云雀短剧/漫剧 Agent** | 对话写剧本、分阶段定稿、全局角色/场景、分镜视频 | 官方操作手册很完整；本轮实开入口需登录，未生成。 |
| 第一组：最贴近需求 | **魔因漫创 Moyin Creator** | 剧本解析、角色三视图、逐镜制作、素材包导出 | 可核查官方工作流文档和开源组件；不是运行验收。 |
| 第一组：最贴近需求 | **LibTV（哩布哩布）** | 剧本/角色工具与 Agent、画布生产连接 | 实际首页与官方插件源码；剧本生成入口弹登录框。 |
| 第二组：对话形态直接竞争 | **TapNow** | 对话开发故事、角色和分镜，画布保留决定，继续出素材 | 官方中文操作文档；国际化官网，本报告按中文创作工作流纳入，不据此推断公司注册地。 |
| 第二组：既有创作者替代工具 | **即梦 Agent / 画布** | 同一输入框承接剧本、参考、技能、主体及生成 | 本轮浏览器可见入口与官方首页；未验证完整内部流程。 |
| 专项对照：素材交接 | **ArcReel** | 面向中文小说/剧情视频生产，提供可编辑包与剪映草稿 | 官方文档及开源实现，不据此推断商业规模或普及度。 |

这些是按需求重合度排的研究优先级，不是市场占有率榜单。垂直工具、开源桌面工具和在线 SaaS 不能混用用户数、月费或融资来判断同一件事。

补充筛选：万兴剧厂是相关的垂直样本，详见[一手来源补充报告](china-video-story-tools-sources-2026-10-01.md)。可灵适合作为视频生成与灵动画布替代路径观察，但本轮未取得足够细的官方剧本/角色/分镜项目文档，不用第三方导航站替它补齐能力。巨日禄同样保留为候选，未核实的功能不写成事实。搜索发现的其他站点不因关键词齐全就自动晋升为核心竞品。

## 2. 小云雀：最该先拆的直接竞品

### 对话里有阶段，阶段里仍能修改

官方剧本助手把写作拆成故事设定、分集大纲、剧本正文；支持持续讨论、定点修改、历史查看/比较/回退。由此可见，对话与阶段引导能够共存，不能过早把它们列成互斥方案。[官方剧本助手](https://xyq.jianying.com/tutorials/short-drama-agent-script-assistant)

### 全流程的具体承接物

官方 Web 手册的路径是：导入/生成剧本 → 编辑概要与全局设定 → 提取角色及妆造 → 提取场景 → 分集故事板增删镜头、编辑提示词、引用资产、单独或批量生成 → 合成导出。对象已经具体到“角色在不同集的造型”，并非只有一张泛用角色图。手册确认成片导出，但本轮没有核实完整素材 ZIP 的目录和内容。[官方 Web 手册](https://xyq.jianying.com/tutorials/web-manual)

### 角色三视图与局部返工

其资产画布提供角色/场景专门节点、三视图、打光和机位工具；节点之间的引用关系决定上下文。官方称资产一处修改可联动下游，但**不能把这句话解读成已生成视频会免费自动重做**：任务、版本和扣费的精确语义未验收。[官方资产画布手册](https://xyq.jianying.com/tutorials/short-drama-agent-canvas)

智能预演先规划一组分镜图，确认后再生成视频。文档给出的单图返工路径是：进画布编辑 → 生成新图 → 加入素材 → 拖回编辑器。这是值得同题检验的操作成本；不能仅凭步骤多就断言用户不喜欢。[官方智能预演指南](https://xyq.jianying.com/tutorials/short-drama-agent-smart-preview)

**对我们的影响（推断）**：对话写剧本、角色三视图、分镜生成这些环节已有直接竞争。差异化必须具体到“用户改一镜时少搬运几次、能保住哪些已完成内容”，不能停在“我们也有 Agent”。

## 3. TapNow：自由对话如何落成制作资料

Brainstorm 通过问答和候选推进故事、人物与世界观，把确认内容整理到画布，再进入图片/视频制作。对于“现在还没想明白”的创作者，它展示了生成前对话可以承接什么。[官方 Brainstorm](https://docs.tapnow.ai/zh/docs/agent/find-ideas-with-brainstorm)

它把单件素材、一组主体参考、可复用节点流程分为不同对象。主体包含名称、描述和多种媒体参考，可在视频节点引用；模型和模式仍限制引用能力。因此“角色”应是可复用参考集合，而不能只等同于一张三视图。[官方主体文档](https://docs.tapnow.ai/zh/docs/canvas/create-and-use-elements)

它允许对话分叉，也明确提醒旧要求不会自动判定失效，建议将已确认/待确认/旧版资料放到画布并只引用当前有效版本。[官方对话管理](https://docs.tapnow.ai/zh/docs/agent/manage-conversations)

生成提供自动执行和手动确认两种模式；手动卡片能检查模型、规格、数量和参考资料。[官方生成模式](https://docs.tapnow.ai/zh/docs/agent/choose-a-generation-mode)

批量下载是当前媒体源文件打包：文字、空节点和仍生成中的节点被跳过，重复文件去重；分组下载只覆盖第一层。**这是媒体打包，尚不能证实它同时交付剧本、角色设定和分镜关系。**[官方批量下载](https://docs.tapnow.ai/zh/docs/canvas/download-in-batches)

**对我们的影响（推断）**：长聊天之外有可引用的当前资料，已经是明确的产品做法。“带关系的制作包”有可能比散落媒体更有价值，但须对竞品真实导出包和创作者交接过程测试，不能直接宣传独有。

## 4. LibTV 与即梦：用户已有的一站式替代方案

LibTV 当前公开首页同时列 Agent、画布、剧本生成、角色造型室和导演工具。本轮浏览器点击“剧本生成”出现登录框，故仅核实入口，内部编辑深度留给官方源码证据与后续实测。[LibTV 官网](https://www.liblib.tv/)

官方集成仓库说明 Agent 会话绑定项目，并提供结果下载操作。它证明已有“项目—会话—生成结果”关系，不能把第三方接入接口支持直接当作网页端完整版本管理。源码证据详见[补充报告](china-video-story-tools-sources-2026-10-01.md)。[LibTV 官方仓库](https://github.com/libtv-labs/libtv-skills)

即梦浏览器首页可见生成/画布入口、剧本与参考输入提示、主体入口；官方页面列出分镜与角色相关技能。它是熟手现成可用的替代路径，但本轮没有进入登录态编辑器验证素材包或镜头版本管理。[即梦官方入口](https://jimeng.jianying.com/ai-tool/home)

**对我们的影响（推断）**：新入口和更多模型不足以让用户迁移。应测试同一个故事的修改与交付任务，比较用户需要手动组织的次数，而非用首页功能数量给产品排名。

## 5. 魔因与 ArcReel：与资源包目标更贴近的实现参照

魔因官方工作流与源码中可核查三视图生成配置、剧本/分镜管理以及首帧、视频、尾帧等素材导出。它与“分步做剧本、角色、分镜，最后交素材”高度重合，优先级应高于专业剪辑软件。具体文件路径、提交证据与限制见[补充报告](china-video-story-tools-sources-2026-10-01.md)。

ArcReel 的官方导出流程是选项目和集数、选择声音版本与剪映版本、填写草稿路径、下载 ZIP、解压到剪映草稿目录。包里包含草稿 JSON 与媒体，提供时间线和字幕等结构；仅含成功生成片段，CapCut 兼容性未验证。**这说明 ZIP 既可以是纯素材包，也可以承载目标工具草稿，必须按用户下一步工作定义。** 本轮未实际导入剪映。[官方导出文档](https://docs.arc-reel.com/guide/jianying-export/)

**对我们的影响（推断）**：上一轮直接把工程适配放到很远以后，缺少国内工具链依据。如果用户主要去剪映，应该尽早测一次实际交接，判断纯素材包是否造成大量重新排列、对字幕的劳动；不能因为 ZIP 易做就把它当终点。

## 6. 同一任务下，应怎样比较

研究用固定样本：“雨夜，一个女孩把伞留给陌生人，结尾发现是未来的自己”。一集、两名同源角色造型、四镜。这里只定义对照，不实际发起付费生成。

| 检查点 | 要记录的真实行为 | 为什么影响产品选择 |
| --- | --- | --- |
| 从一句想法起稿 | 追问什么；何时出大纲；能否停止在文本阶段 | 对话有没有帮助想清楚，而非立即烧积分 |
| 角色定稿 | 主图/三视图/造型版本怎样存；镜头怎样引用 | 能否承接连续角色与同人不同造型 |
| 改一段台词 | 定位方式、保留哪些原文、是否有回退 | 文本迭代是否稳定 |
| 改第 2 镜机位 | 是否跳页、手搬图、重绑参考；其余镜头是否改变 | 局部返工实际成本 |
| 改角色衣服 | 下游提示、旧片保留方式、是否默认触发生成 | 改动影响和成本可控性 |
| 只生成两镜 | 单镜/批量选择、预估费用、失败重试颗粒度 | 支持探索式制作还是强推全剧完成 |
| 导出交接 | ZIP 实际文件树、剧本/镜号/引用是否留存 | 用户带走后是否还知道哪个素材对应哪镜 |
| 去剪映继续做 | 导入、重排、字幕、声音处理需要多少操作 | “导出”有没有真正完成交付 |

先记录操作数、切换次数、引用重绑次数、影响范围是否可解释、导出缺项；生成质量则同题生成后由创作者评价。没有这些实测数据，不写“更好用”“更一致”“更省钱”。

## 7. 对上一轮结论的修订

1. **核心样本改为国内短剧/漫剧和影视 Agent。** 国外产品只留作外围参考，不再作为选型论据。
2. **撤回已经选定“文档优先”的口吻。** 当前更值得验证的是对话推进、阶段可见、资产可复用、镜头可操作的组合；具体主工作面仍未定。
3. **不再淡化三视图。** 国内直接竞品将它当作明确的角色制作能力，我们应该提供和测试；是否每项目必做是另一问题。
4. **资源包不是天然差异化。** 国内已有素材导出和剪映草稿先例，必须比文件完整性、关系保留和交接劳动。
5. **候选突破点缩到可测的工作。** 在当前镜头里完成对话修改，清楚显示关联影响，保留可用候选，减少跨页搬素材，以及能接着做的导出。全部是待验证假设，不是竞品普遍缺失的事实。

## 8. 本轮证据边界与浏览器记录

- **官方文档级**：小云雀、TapNow 的操作流程；ArcReel 的导出步骤。文档可证明厂商描述了什么，不证明每个账号已开放或效果达到宣传。
- **官方源码级**：LibTV 官方集成、魔因开源实现、ArcReel 实现，详见补充报告；源码不等于已在本地运行。
- **浏览器入口级**：小云雀公开首页及登录页；即梦首页；TapNow 官网；LibTV 首页及剧本生成登录弹窗。未登录、未消费生成积分。
- 小云雀本机未登录首页的宣传版本与公开教程中的模型版本不同。因此本报告不把动态页模型名称、价格或版本作为功能上线时间证据。
- 本轮不报告付费用户数、市占率或真实单位交付成本。促销价格没有统一模型、清晰度、重试与成片可用率口径，不作排名。
- SEO 聚合站、近似官网域名与未经验证的第三方教程仅用于发现线索，不作为结论来源。

这次完成的是国内同赛道的证据筛选与流程拆解；真正的同题账号操作、质量比较及导出包验收仍待进行。下一次原型应以这些产品的具体操作为基线，而不是再凭通用布局直觉选方案。
