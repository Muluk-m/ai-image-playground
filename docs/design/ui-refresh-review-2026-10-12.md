## 三种可比布局

- A 紧凑工具栏：素材与输入并排，类型、模型、参数在底栏，最接近用户参考。代价：参数需要展开查看。
- B 分层输入区：顶部类型切换，素材独占一行，下方完整输入区。代价：占用更大纵向空间。
- C 侧边参数栏：类型与输入在左，参数常驻右侧。代价：占用更多宽度，窄屏参数移到底部。

验收工具栏位于底部，可切换布局与创作首页、画布、项目列表、视频卡片四个场景。资产面板从顶栏「资产」或 Composer 的添加菜单打开。

## 实现与边界

共享源码：`components/creation/CreationComposer.tsx`、`draft.ts`、`MediaGallery.tsx`、`creation.css`。
现有复用：PromptEditor 与引用哨兵/胶囊、MediaImage、ModelLogo、ProjectCover、VideoPlayer、BrandAvatar、shadcn Button/Select/Popover/Input、主题 token、字体及现有 public 资源。

`features/creation-review` 仅包含演示宿主、样例数据与验收工具栏。上线时业务入口使用相同共享组件与 CSS，接入实际模型能力、草稿及提交链路；不另写一份视觉近似实现。

Demo 只在 Vite 开发模式及 `?prototype=creation-review` 下启用，不访问真实会话、不提交生成任务、不扣费。模型参数是演示数据，尚不代表在线能力；视频封面演示不能证明生产缺失封面问题已修复。画布仅呈现节点上下文，未接入真实画布编辑器。项目操作、回收站以演示反馈表示，未修改项目数据。草稿暂存于组件内存，刷新清空，符合目前明确的类型切换保留范围。

文件上传仅保存在本次页面的 object URL，页面卸载释放。素材选择为追加，不会因为切类型或切列表范围删除原参考素材。

## 运行

```sh
pnpm --filter @image-playground/web dev --host 127.0.0.1 --port 5179 --strictPort
```

打开 `http://127.0.0.1:5179/?prototype=creation-review&variant=A`（B / C 可切换）。

用户验收后再接入真实业务、排查生产视频封面链路，完成 CI、发布与线上验收。

## 第一轮验收调整

- 移除模板行、右上角展开按钮及底栏重复引用入口；保留参考区作为素材入口，已添加素材仍可点击插入引用。
- 发送改为圆角方形，空输入使用中性灰底，输入后变为高对比可用态。
- 类型菜单增加宽度与行间距，选中勾放右侧。
- 比例选项按实际数量均分行宽，2/3/5/6 个选项均不留空槽。

## 第二轮验收调整

- 缩短素材/输入区与底栏的间距，取消多余固定高度；长文仍可自然撑高并滚动。
- Agent 提示围绕目标、脚本与创作步骤；图片提示围绕主体、场景与风格；视频提示围绕动作、运镜与氛围，中英文同步更新。

## 第三轮视觉精修

- 参考入口改为轻描边方形素材卡，统一图标尺寸与圆角。
- 底栏统一 40px 高度与文字规格；类型为轻强调底色，模型与参数使用轻量工具样式，参数去掉突兀的黑色胶囊。
- 参数摘要直接展示画幅形状，类型与模型之间用细分隔线区分层次。
- 输入提示限制行长并调整行高，外框与聚焦态减弱，保持紧凑布局。

## 参考区间距校正

参考入口周围采用统一间距：桌面上、左、右侧输入区及下方工具栏均为 24px；窄屏统一为 20px，并保持纵向排布。所有间距来自同一个组件变量，避免分别压缩造成失衡。
