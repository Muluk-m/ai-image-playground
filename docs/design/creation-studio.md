# 对话创作台

默认首页为创作；品牌按钮返回创作。主导航顺序为创作、作品、视频（仍按部署能力显示）。商品图前端页面、状态机和执行工作流移除，旧商品任务在作品中继续按组展示；只读元数据兼容层保护其名称、动作标签与图片引用，不删除浏览器存档。

桌面采用左侧对话、右侧独立画布。画布容器拥有自己的坐标系与尺寸，侧栏拖宽或收起后由既有 ResizeObserver 更新视口，放置和鼠标命中无需额外偏移。智能体能力关闭时，左侧替换为直接图片生成；参数、选图迭代、标注与多图提交仍使用原有逻辑。移动端侧栏覆盖画布，可收起；直接生成侧栏支持滚动。

视频入口（`/video`）不是画布，而是一张居中落地页：上半是视频输入卡（图片/视频切换、模型与时长
画幅清晰度档位、描述、通栏提交），下半是快捷工具与案例。快捷工具只放此刻真能执行的动作（挑素材
当首帧、挑参考图、灵感库、我的作品），案例取灵感库条目，点一下把提示词填回输入框。提交不在落地页
起轮：描述与视频档交给画布，画布挂载且工作区就绪后才发一轮，产物仍落在画布上；没有智能体的部署
回落到画布生成栏的视频提交。

画布上不再浮动生成栏。空对话的输入只在左侧（智能体面板，或智能体关闭时的直接生成侧栏），画布区域
只承载作品与工具条。

全站共用 `apps/web/src/styles/theme.css` 中的 shadcn 语义 token，Tailwind 将 background/foreground、card、popover、primary、muted、accent、border/input/ring 等映射为工具类；创作、作品、视频、登录、设置及付费账户面板不维护独立调色板。遵循现有 `darkMode: media`，跟随系统深浅色。芽绿用于主要操作，必须与 primary-foreground 成对使用；错误/警告使用状态 token，画笔内容色和媒体遮罩不随主题改变。二维码使用固定白底以便扫描。

顶部品牌、导航、账户操作保持一排，高度 56px；窄屏隐藏品牌文字。取消灵感库与素材库的自动引导弹框及脉冲，入口仍可主动打开。移除侧栏宣传标题，编辑器只在容器上显示一次焦点环。

空画布引导支持本地图片导入。对话输入继续支持引用、拖入参考图、遮罩、草稿、流式回复、会话和图层。生成结果保存、任务恢复、下载和历史复用沿用现有数据路径。

新产物完成写入当前项目后自动选中并移入画布视口，不需要再点击对话里的结果缩略图。后台项目的结果仍写入原画布，但不移动当前项目或已离开项目的镜头；重复交付与历史重放不再次抢走镜头。

技能引用在输入框和用户消息中统一显示为「技能图标 + 标题」的行内胶囊；仅识别部署技能列表中的行首命令，未知命令和句中斜杠保持原文。图片引用在输入框、发送中的用户消息和已发送历史中都显示实际缩略图，有素材名时同时显示名称。消息只使用自己发送时的有序参考图快照，不能借用当前草稿或画布里的同序号图片；起轮确认保留本地预览，重开历史通过校验会话归属的消息参考图端点读取服务端缩略图。没有对应快照的旧编号保持原文，不猜测图片。

消息中的参考图胶囊支持点击或键盘打开原图预览，复用现有图片查看器的缩放、拖动和关闭操作。当前消息使用提交时的本地原图；历史消息点击后才通过同一个受保护端点的 `variant=original` 读取完整原图，而不是放大 96px 缩略图。会话或账号变化时关闭旧预览，中止请求并释放临时图片地址；读取失败在弹层中明确提示。

草稿仍存技能标识 `/skill-name` 与图片引用哨兵，发送时图片引用仍转成 `[image N]`，显示标题、缩略图不改变请求协议。光标定位、整颗删除、复制粘贴与草稿恢复按原始引用语义处理。图片/视频切换菜单显示「图标 + 文字」，选中后的入口只显示当前类型图标，悬停提示和无障碍标签保留类型名称。
