# 智能体画布可靠性修复

本次范围是插话引用、草稿恢复、历史阅读滚动、画布保存失败提示。

- 插话与普通消息一样携带图片及遮罩。后端归档插话引用，送给模型，并供本轮工具与后续轮引用。上传时若轮已结束，明确拒收；失败清理不得删除同一轮的其它引用。
- 草稿按当前账号和会话保存在本地，包括文字、图片和遮罩。收起面板、切页签、刷新后可恢复；首次创建会话时迁移草稿。服务端接收之前不清空，发送失败可重试，等待期间的新编辑不得被发送确认覆盖。
- 阅读历史时流式消息不强制滚到底部；用户回到底部后继续跟随。
- 画布以 IndexedDB 事务提交完成作为保存成功；失败在画布上显示持续提示及重试入口，重试成功移除提示。

验证边界：输入框与面板组件、客户端发送接口、草稿和场景持久化、BFF 插话路由及归档恢复。BFF 全量测试纳入 CI，图片上游与对象存储均使用测试替身。

项目／画布身份绑定、画布结构理解、方案版本管理不在本次范围。
