# 商品图连续创作

用户于 2026-09-10 确认三个 demo，沿用商品图原图 / 预览 / 设置 / 版本 / 结果总览布局。

- 局部修改：在当前完成版上框选，输入要求，产生新版本；可滑动或并排对比、选用、继续修改。原图和旧版本保留。框选引导编辑，不承诺区域外像素不变。
- 做成一套：从完成版生成方形主图、竖版海报、横版广告，支持中文 / 英文。每个尺寸与语言组合独立提交，可修改文案、单张重做并打包原尺寸结果。
- 先看方案：从原图与偏好生成三个不同方向，选中完成方案后精修；方案与成品都保存到版本。模型从可用配置选择，快速与精修分别配置，不全局切换模型，不静默扩大生成数量。
- 所有生成复用提交与计费入口，保留来源图、来源版本、实际参数与任务关联；失败可重试，刷新可恢复版本，切换任务不把结果记入另一任务。
- 不修改认证、同步和原有商品替换逻辑；旧数据无需迁移。

验收：版本来源与独立重试的状态测试；模型选择与尺寸语言展开测试；前端类型、格式、测试；浏览器检查三条交互。
