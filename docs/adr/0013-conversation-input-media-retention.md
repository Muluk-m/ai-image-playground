# 会话上传输入随会话保留，并计入统一媒体容量

状态：accepted（设计决定，尚未实施）。确认日期：2026-10-01，用户在多图方案访谈 Q5 确认。

用户已经发送的图片输入需要在旧会话中继续被查看和处理，因此复用持久媒体及会话引用，并计入现有用户媒体容量；不采用附件固定期限过期、旧会话要求重新上传的默认策略。删除会话后，仅当该媒体没有其他有效引用才可回收；未发送附件只短期保留，不能因一次拖入就永久占用存储。

这项决定只规定用户上传的会话输入，不自动把附件加入素材库，也不把生成产物升级为长期保存，维持 [ADR 0011](0011-cloud-storage-limited-to-assets.md) 的产物存储边界。参考图、遮罩及其派生预览复用 [ADR 0008](0008-durable-project-media.md) 的容量与引用归属，不建立第二套资产库。代价是需要把未发送附件清理、会话删除与并发引用安全落实后，才可扩大到批量上传。
