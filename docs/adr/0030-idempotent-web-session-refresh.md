# 网页会话轮换可重复交付

## 问题

刷新事务会立即退休旧 refresh 并删除旧 access，但新 Cookie 只通过 HTTP 响应交付。响应丢失后，旧实现超过 30 秒就作废整条链，无法区分合法重试与盗用。降低轮换频率不能恢复已提交的结果。

## 决定

浏览器先在独立 IndexedDB 中，以实际 BFF 地址为 scope，用 readwrite 事务原子取得随机 UUID 请求标识，再通过 `x-session-refresh-request` 发请求。网络、JSON、5xx 或 409 失败保留 pending；成功确认用比较后写入完成状态，旧响应不能清除下一次 pending。保留最近一次完成标识，用于一次延迟 Cookie 回退的恢复。Web Locks 只减少并发，不承担持久化正确性。

后端仍由 `user-session.ts` 独占轮换、过期与撤销。继任 refresh 为 `r1.<请求标识的SHA256>.<HMAC>`；HMAC 使用前驱凭据为密钥，输入包含版本、family ID 和请求标识。继任 access 从继任 refresh 用独立 domain 的 HMAC 导出。数据库继续只存令牌哈希，不保存明文、密文或额外密钥，新增一个可空的 `request_key_hash` 列与 `(family_id, request_key_hash)` 唯一索引；旧版本写入 NULL 仍兼容。

- 当前令牌与新请求标识：正常轮换，退休行同时记录标识哈希。已经执行过的标识不能在更新一代 Cookie 上再次轮换，返回 409。
- 当前令牌携带相同请求标识：恢复同一结果，处理 Cookie 已写入但 JSON 丢失。
- 已退休令牌与相同请求标识：推导继任；继任哈希等于当前 family 哈希时重发原结果；等于同 family 的退休哈希时返回 409，不恢复过时凭据。
- 不能证明的旧令牌：拒绝认证。30 秒内保留兼容并发提示，但经过时间本身不再导致整链吊销。持有旧令牌不能通过此接口踢掉仍然有效的其他客户端。

恢复保持原有效期和数据库状态。access 原到期时间可由 `refreshed_at + 7天` 与绝对上限推导，即使过期 access 行已清理也不需要收据表。恢复时 access 已过期、refresh 仍有效的，前端确认恢复后用新请求标识再进行一次正常轮换。所有路径继续检查 family 撤销、用户状态、30 天 refresh 与 90 天绝对上限。

旧 access 升级使用同一协议。改密码仍签发独立随机 refresh，使旧请求无法恢复密码变更前的凭据；退出、改密码、禁用及管理员吊销继续生效。登录凭据及恢复标识不进入日志或截图。

## 取舍与合成

两个独立候选比较了确定性继任与持久收据表。采用确定性继任：现有 family 已有恢复所需到期时间，新增表重复存储可推导状态。独立实现复查发现暂停标签页可能重用已完成标识，对更新一代 Cookie 产生额外轮换；因此把已消费标识哈希记录到退休行，作为最小持久操作收据。纳入收据方案的固定到期语义和过期 access 的两步恢复；纳入另一候选的 current-token 请求摘要，覆盖只丢 JSON 的情况。拒绝稳定 refresh、扩大时间宽限、IP/User-Agent 识别及 localStorage 非原子的读写方案。

本次移除的是基于歧义信号的自动整链吊销，旧凭据权限仍被拒绝。盗取前驱令牌与对应请求标识的组合等同取得该次恢复凭据；只取得数据库哈希或请求标识均不足以换取会话。

## 边界与发布

迁移 0093 仅新增可空列与索引，不修改已有迁移；0092 为其它会话尚未提交的找回密码迁移保留。新 journal 时间戳位于 main 的 0091 与该未提交迁移之间，避免提前越过其时间戳。

先发布支持协议的后端，再发布带持久标识的前端。旧客户端不传标识仍能正常刷新，但已由旧代码随机签发、响应丢失的结果无法追溯恢复。已被旧版本吊销的会话仍需重新登录。

持久存储不可用时在发起轮换前返回临时失败，避免发出无法跨重载恢复的操作。任意多代、任意延迟的 Set-Cookie 回退无法用一条 pending 和一个 completed 标识完整修复；无法证明的回退拒绝认证，不会吊销健康 family。Cookie 本身过期或被清除后不绕过登录恢复。

## 验证

`auth-refresh.test.ts` 覆盖丢响应超过宽限后的相同结果、只丢 JSON、并发、过期 access 清理、错误证明、禁用再启用与登出。`sessionRefreshJournal.test.ts` 覆盖无 Web Locks 的原子 acquire、API 隔离和旧 completion 不覆盖新 pending；`authClient.test.ts` 覆盖重载后的持久请求标识、正文中断和过期 access 的恢复后轮换。
