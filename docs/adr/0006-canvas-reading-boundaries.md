# 会话范围内的画布读取、观察更新与资料等待

大画布的渐进读取会跨多个观察和操作，期间用户可能修改画布或关闭页面。沿用 ADR 0005 的会话画布归属，本次选择会话限定的读取范围、按相关变化重新读取，以及缺少资料时保存进度等待；这些是已确认的产品约定，尚未实施。

## 决策

- 默认可查本会话的整张画布与历史，并沿用素材库既有访问规则；其他会话的画布或历史须由用户明确指定后引入，不自动搜索全部会话。选区用于表达关注对象，不构成画布内查找限制。
- 在执行下一项相关操作前核对画布观察是否过期；目标或依赖变化时重新读取、重新判断，无关对象变化不打断工作。已提交的生成操作继续使用提交时锁定的图片，不能在执行中替换输入。
- 浏览器关闭后继续处理服务端已有资料；依赖尚未上传图片的工作保存进度，等待页面重新打开、资料可用后继续。首版不要求整张画布的全部图片预先上传才能起轮。

## 取舍与后果

相较于自动跨会话搜索，这一范围减少旧任务要求混入当前创作，同时保留显式引入其他会话资料的路径。相较于整轮固定旧版或每步无条件追随最新画布，按依赖更新能兼顾用户编辑与执行稳定性，但需要分清对象变化影响哪些观察。

资料按需准备减少任务开始前的上传负担，代价是浏览器关闭后不能保证完成所有尚未取得资料的工作；“保存进度”是待建设能力，现有轮在 BFF 进程内继续运行并不等于已有可恢复检查点。具体存储方式、恢复后的轮与计费关系仍待后续设计确认。

本决策不授予自动跨会话搜索范围，也不决定长期记忆、历史版本保留期限或全画布检查预算。已提交操作的版本锁定与“产物交付”“画布冲突”继续分别处理，不改变现有产物交付规则。

后续领域方向见 [ADR 0008](0008-project-context-and-execution-windows.md)：项目能力引入后，默认读取归属由会话演进为项目；本 ADR 的变化校验与资料等待规则继续适用。
