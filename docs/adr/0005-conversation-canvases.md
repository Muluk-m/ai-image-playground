# ADR 0005：项目画布保留本地可靠性

## 决策

- 项目成为稳定的画布归属，拥有独立项目 ID；会话 ID 只作为关联信息。#416 已交付本地项目管理，#433 增加文字和标注的云端恢复；服务端会话绑定由 #437 补齐。原有会话画布键仅用于兼容旧存档。
- 首次发送前使用未绑定草稿画布。创建会话后，原子转存草稿并保留原文档、选区与撤销栈；转存失败不发起生成，保留草稿供重试。
- 新建会话回到未绑定草稿；没有草稿时为空画布。已经处于新会话时再次点击不会清空未发送内容。
- 切换会话恢复各自场景；运行中禁止切换、新建或删除当前会话。生成已结束但图片仍下载时可以切换，晚到结果仍交付给原画布并保存。
- 画布文档生命周期独立于视图挂载。切换模式和会话不取消已发起的画布任务。页面生命周期事件立即保存脏文档，未修改的旧标签页不覆盖存档。
- 读取失败显示重试入口并阻止编辑/保存，不能将读取失败解释为空画布。保存失败保留内存文档并提示重试。
- 旧版只有一个无账号标记的全局场景：首次升级打开画布时，认领给浏览器记住的当前会话（没有会话则给草稿）。事务中记录唯一认领者，旧记录保留为备份，其它会话与账号不能再次自动认领。
- 本地项目沿用现有删除语义；云端项目删除与会话回收将在 #439 统一实现，本阶段不允许走本地删除流程销毁云端项目。

## 验收

1. A、B 会话的元素、相机与撤销操作互不影响；刷新后分别恢复。
2. 在未发送会话中先绘图，首次发送成功后画布不闪空、不重建文档；保存失败时不发起生成。
3. A 的图片下载期间打开 B，图片只落入 A；回到 A 可见，B 不被污染。
4. 旧场景只迁移一次，备份不变；账号存档键互相隔离。
5. IndexedDB 读取失败不覆盖原存档，保存或绑定事务中止后可重试。

## 云端恢复边界

云端加载错误必须阻止编辑并提供重新读取入口，不能用空场景替代。新设备只恢复画布内容并适配视口；已有设备保留自己的相机状态。未修改的旧页面不发起保存，修订冲突后保留本机内容并暂停自动写入。每个已打开项目持有自己的修订基线，不借用另一标签页的新版本覆盖旧文档。
