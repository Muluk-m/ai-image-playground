# 生成原件长期保留与默认云同步边界

状态：**superseded（2026-09-19）**，由 [ADR 0011 云端存储止于资产与会话](0011-cloud-storage-limited-to-assets.md) 取代。原确认日期：2026-09-17。下文保留原义供追溯，**不再作为实施依据**：#483 全停、#422 仅保留 #440，云端只承载资产与会话，已上线的云端生成历史只停止扩张、不回退删除。

用户确认：平台执行的生成内容自动进入用户云端；浏览器使用用户自己的 API Key 直连生成的内容，由用户选择是否上传，密钥永不上传。云端生成原件在容量配额内长期保存，由用户主动删除，不随执行任务的保留期限到期；不采用普通结果限期保存、只对收藏长期保存的方案。

这取代 ADR-0002 中“普通生成记录保持本地、结果仅按运行态保留”的范围决定。取舍是平台承担持续媒体存储成本，以保证用户换设备后仍能访问原件；执行记录和用户拥有的创作内容因此必须有独立生命周期。

用户进一步确认采用完整创作内容云同步、本地缓存及完整导出导入：生成记录、原件、项目画布、分镜、商品图任务和已保存草稿均纳入；光标、选区、弹窗、相机与撤销栈保留本机。具体容量和保留参数使用规格中的可配置初始值，不作为用户逐项确认的套餐承诺。旧 ADR 中与本决定无冲突的设置、模板、素材、身份边界保持原义。
