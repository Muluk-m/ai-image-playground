# 创作目标约束与历史证据分开管理

一个会话可能先后推进不同创作目标，持续压缩既可能遗失要求，也可能把旧要求错误带入新目标。约束按创作目标及其对象生效，实际参与工作的版本资料保留为可回读历史证据；这些产品约定已确认，尚未实现。

## 决策

- 同一创作目标的续改继承目标约束，换目标不自动继承。明确的长期偏好另行保存，不以会话内出现过某句话作为永久生效依据。
- 保留智能体实际读取或生成过的准确版本；删除或替换画布对象不自动清理历史证据，另设明确清理入口。不要求记录每次拖动、缩放等全部编辑快照。
- 全画布检查先在默认费用额度内执行；达到总额度时暂停，展示已检查范围、发现和剩余进度，由用户决定是否追加额度续扫。阶段性检查不能报告为全部完成。

## 取舍与后果

按目标管理要求需要维护约束的适用范围，但能同时支持跨轮续改和目标切换。保留已使用版本增加存储负担，换来删除画布对象后仍可恢复准确证据；清理入口必须说明其对历史回读的影响，具体期限与容量策略仍待确认。

持久保存历史证据不等于把它们持续放入模型输入。窗口切换应在已有授权与费用额度内自动推进，不把上下文容量用尽等同于费用额度用尽。[ADR 0008](0008-project-context-and-execution-windows.md) 后续确认窗口切换维持同一用户可见会话，并明确未来项目拥有独立上下文；交接内容与恢复协议仍在设计中。
