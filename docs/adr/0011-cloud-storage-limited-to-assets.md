# 云端存储止于资产与会话，生成产出停止扩张

状态：accepted。确认日期：2026-09-19。**Supersedes [ADR 0007 生成原件长期保留与默认云同步边界](0007-durable-generation-cloud-ownership.md)**，并恢复 [ADR 0002](0002-sync-templates-assets-not-generation-records.md) 的成本取舍。排期见 [ROADMAP](../ROADMAP.md) Lane B1（裁决 G1）。

云端只承载两类数据：**用户资产**（模板、素材含图片本体、用户设置）与**智能体会话**。生成产出、项目画布、草稿不再扩大上云范围。

ADR 0007 承诺「平台执行的生成内容自动进入用户云端，在容量配额内长期保存」，代价是平台承担持续媒体存储成本。实际推进中该成本不可收敛：对象存储占用与带宽随**生成量**线性增长，而付费只与用户数和积分消耗挂钩，两条曲线不同阶。ADR 0002 当初的判断成立——模板与素材是用户反复投入的**资产**，丢了要重做；生成结果是**产出**，量大、一次性。

## 范围

| 数据 | 归属 | 依据 |
| --- | --- | --- |
| 模板、素材（含图片本体）、用户设置 | 云端，长期 | ADR 0002 原义，#176 已交付 |
| 智能体会话与对话历史 | 云端 | 裁决 F1；运行时在 BFF 进程内（[ADR 0003](0003-agent-runtime-in-bff-process.md)） |
| 生成产出原件与预览 | **已上线部分保留，不再扩张** | 本 ADR |
| 云端项目的画布结构文档（#422 / #433 已上线） | **已上线部分保留，不再扩张** | 本 ADR |
| 本地项目、草稿、导出导入 | 本机 | 本 ADR |
| BYOK 密钥 | 永不上云 | ADR 0002 |

会话留在服务端不是存储选择，是架构约束：流式 SSE、工具调用幂等、刷新后任务恢复都依赖服务端会话；且吃存储与带宽的是媒体原件而非文本。

## Considered Options

- **只停止扩张，已上线部分原样保留。** 采纳。`generation_images` / `media_objects` / `durableMediaStore`、前端 `CloudTaskTile` / `CloudGenerationDetail`，以及 #422 / #433 交付的云端项目结构同步（修订号 + 乐观并发 + 回收站）都继续跑，不拆链路、不删用户既有数据。成本靠配额、保留期与无引用回收压平。
- **主动回退删除，彻底回到 ADR 0002。** 存储成本最低，但要拆已上线链路并删除用户已有数据，工期不低于把 #483 做完，且产生一次可感知的数据丢失。未采纳。
- **维持 ADR 0007，做完完整云同步（#483 + #422 共 32 片）。** 体验最完整，但存储与带宽随生成量线性增长，且会吃掉接下来绝大部分工期。未采纳。

## Consequences

- [#483](https://github.com/Muluk-m/ai-image-playground/issues/483) 完整创作云同步与数据可携带（#501–#516，16 片）全部停止。
- [#422](https://github.com/Muluk-m/ai-image-playground/issues/422) 云端项目同步剩余切片中，#441–#445 停止；**[#440](https://github.com/Muluk-m/ai-image-playground/issues/440) 无引用媒体回收与容量释放保留**——它是省成本而不是加成本。
- 「换设备还在」的承诺范围收窄为资产与会话，不含生成产出。产品文案与容量展示需按此口径修订，不得暗示产出长期云端可取。
- 成本治理按此顺序落地：#440 无引用回收 → 每用户原件配额 + 保留期（参数走 operator-config）→ 预览图分辨率降级（`projectMedia.ts` 目前每张原件都生成 WebP 预览，是带宽主项）。
- 不新增任何「把产出上云」的代码路径。判据：存储成本随注册用户数增长，而非随生成量增长。
- ADR 0007 中「BYOK 直连内容由用户选择是否上传、密钥永不上传」的身份与密钥边界保持原义。
