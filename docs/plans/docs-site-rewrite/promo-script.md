# 幕芽站点宣传片脚本（45–75 秒）

成片目标：一条 16:9 站点宣传片，素材全部来自 `test.muvloom.online` 录好的主流程成片，不另拍空镜。配中文字幕；可用旁白或只留字幕（两条文案已对齐，选一种即可）。不要在画面或字幕里写具体积分数字、成本或毛利。

建议总长 **62 秒**（可剪到 48 秒：删场景 4 与场景 6 的定格）。

## 音乐

轻快、干净的电子流行，中速（约 100 BPM），偏明亮但不吵。前 8 秒只留简单鼓点与铺底，出第一张图时加入主旋律，结尾 4 秒收束，不要用歌词、不要用悬疑或促销倒计时音效。

## 字幕规范

- 每屏不超过 16 个汉字，居下居中，深色半透明底。
- 不出现「失败全额退回」、具体积分数、价格或会员推销口号。
- 品牌名写作「幕芽」；英文域名只在最后一屏出现：`muvloom.online`。
- 不往产品界面里加额外说明文案；宣传片字幕叠在成片外层，不改 UI。

## 导出

- 主文件 `promo-site-zh.mp4`（H.264，1080p，立体声或无声+后期配乐）。
- 另出无配音、仅字幕版本，方便静音自动播放。
