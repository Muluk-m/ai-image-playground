# 幕芽主流程演示视频分镜（可自动录制）

环境：`https://test.muvloom.online`，界面语言中文（`zh-CN`）。
账号：所有生成类视频都需要**已登录**的测试账号（未登录点发送会弹出登录窗，见指南 FAQ）。
不要使用 4K 或「高」画质，除非明确换会员账号——代码里 `preparedComposerNeedsMembership('gpt-image-2.6-flare', { size: '3840x2160' })` 为 true，界面文案有「高画质为会员专享」「当前可用分辨率最高为 2K」。
按钮文案以 `apps/web/src/i18n/locales/zh-CN/` 为准（`origin/main`）。首页创作方式来自 `HomeTargetPicker.tsx`：下拉 `aria-label` 为「选择创作方式」，选项为「智能创作」「图片生成」「视频生成」「画布创作」。旧指南里的「快速生成」在当前界面已改名为「图片生成」。

录制约定：
- 分辨率 1440×900 或 1280×800，光标可见，无声；片头 1 秒站点 URL，片尾定格成果 2 秒。
- 目标时长 30–90 秒（视频生成若上游未在 90 秒内出片，录到画布项目出现即切，不要空等）。
- 选择器优先 `getByRole` / `aria-label` / 可见文本，避免依赖 CSS class。
- 发送按钮：`aria-label` 为「生成 (Ctrl+Enter)」，可见文本「生成」（`composer.submit.generateShortcut` / `studio.send`）。画布开局提交用「开始创作」（`composer.submit.startCanvas`）。
- 参考图夹具：录制前准备两张小于 50MB 的 PNG（例如白底商品图），不要依赖仓库里不存在的路径。

## 01 `01-first-image.webm`（约 45 秒）

- 所属文档：`/guide/start/overview/`（生成第一张图）
- 会员：否。参考图：否。
- 提示词：`一杯冷萃咖啡放在浅色石台上，冰块透亮，午后自然光，商业摄影，3:4 竖构图`
- 预期：输入框下方「我的作品」（`task.mine`）出现一张完成的图片卡片。

点击路径：
1. 打开 `https://test.muvloom.online/image`（创作页，`APP_MODE_PATHS.image`）。
2. 点输入框左下「选择创作方式」，选「图片生成」。
3. 点「选择模型」/「模型」，在「GPT 系列」下选 `Image 2.5 Flare`（或当前默认可用的 GPT 图模；不要选 2.6 本条，给静态首图一条干净路径）。
4. 点「生成设置」，「比例」选 `3:4`，「数量」保持 1 张，「质量」选「中」，点「完成」。
5. 在「描述主体、场景与光影风格，或添加参考图」输入框键入提示词。
6. 点发送按钮「生成」。
7. 等到「我的作品」出现结果图，鼠标悬停卡片 2 秒后结束。

## 04 `04-gpt26-gif.webm`（约 70 秒）

- 所属文档：计划中的 `/guide/create/gpt-image-26/`（现网指南尚未建此页）
- 会员：否。参考图：否（GIF 不能带参考图；带参考图时「动图 GIF」会置灰，见 `ParamControls.tsx`）。
- 提示词：`一只橘色小猫对着镜头挥手，循环动作，简洁白色背景，贴纸风格`
- 预期：生成一张可播放的多帧 GIF（默认 6 帧、768×768，代码默认 `GPT_IMAGE_26_GIF_DEFAULT_FRAMES = 6`、`GPT_IMAGE_26_GIF_DEFAULT_SIZE = '768x768'`）。尺寸只允许 `512x512` 或 `768x768`。

点击路径：
1. `/image` →「图片生成」。
2. 「选择模型」→「GPT 系列」→ `Image 2.6 Flare`（`ModelIdentity.tsx` 文案）。
3. 点「生成设置」。确认格式区出现「图片 / 动图 GIF / 矢量 SVG」（`settings.still` / `settings.gif` / `settings.svg`）。
4. 点「动图 GIF」。此时只应看到 GIF 自己的「帧数」「每帧时长」「尺寸」，不要再改静态图的自定义宽高（自定义宽高会写出非法尺寸并被 400 拒绝）。
5. 帧数选 `6`（选项来自 `GPT_IMAGE_26_GIF_FRAMES`：4 / 6 / 9 / 12 / 16），每帧时长保持 `0.2 秒`（200ms，默认档），尺寸 `768x768`。
6. 点「完成」，输入提示词，点「生成」。
7. 在「我的作品」播放 GIF 数秒后结束。

注意：若测试环境 2.6 开关未开，本条应标记失败并跳过，不要改用 2.5 假装成功。

## 09 `09-canvas-inpaint.webm`（约 85 秒）

- 所属文档：`/guide/canvas/basics/`
- 会员：否。参考图：否，但**先要有一张画布上的图**（本条自己生成）。
- 生成提示词：`一只陶瓷咖啡杯放在木桌上，侧面能看到杯把，自然窗光`
- 改图提示词：`把杯身釉色换成雾面墨绿，杯把保持原样`
- 预期：画布上原图旁或就地出现修改后的结果；智能改图需要支持遮罩的模型（界面说明：请切到 GPT Image 系列）。

点击路径：
1. `/image` →「选择创作方式」→「画布创作」。
2. 输入生成提示词，点「开始创作」。
3. 进入画布后等到第一张图落盘。
4. 按 `V` 选中该图（快捷键表见现有画布指南：选择 `V`，画笔 `D`，文字 `T`）。
5. 在图片操作条点「智能改图」（`canvas.inpaint.action`）。
6. 工具选「框选区域」（`inpaint.tool.rect`），在杯身框一块区域（避开杯把）。
7. 在「描述希望怎么修改…」输入改图提示词，发送。
8. 等到改图完成，并排对比 2 秒后结束。

若按钮置灰，悬停阅读原因（模型不支持遮罩 / 图太小 / 长宽比超过 3:1），记录后中止，不要改走「整图编辑」冒充本条。

## 自动化就绪检查

1. 已登录（页上能看到积分 `credits.ariaLabel`，没有「登录 / 注册」主按钮挡着发送）。
2. `/image` 模型列表加载完成，至少有一个可用 GPT 图模。
3. 拍 04/05 前，模型列表里看得到 `Image 2.6 Flare` 或 `Image 2.6 Sunburst`。
4. 拍 10 前，`/explore` 至少有一张案例卡片。
5. 夹具图片存在且可被 file chooser 选中。
